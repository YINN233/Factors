# 国信证券联合动量因子复现设计

## 1. 目标

复现《20240109-国信证券-金融工程专题研究：个股与行业的共振，联合动量因子.pdf》中的核心因子和主要检验结果，重点覆盖：

- 个股最大收益日对应的行业收益因子 `IMAX20`；
- 行业联合动量因子 `ICM`；
- 量价齐升行业联合动量因子 `VICM`；
- 行业联合反转因子 `ICR`；
- 量价齐跌行业联合反转因子 `VICR`；
- 行业联合动量复合因子 `CMC = VICM - VICR`；
- 市场联合动量复合因子作为拓展检验；
- RankIC、ICIR、分组收益、多空收益、参数敏感性和不同股票池表现。

本任务的目标是方法和结果尽量贴近 PDF，而不是无条件声称与 Wind 原始结果完全一致。

## 2. 已确认的数据条件

### 2.1 可直接使用的数据

本地已有：

- 中证500历史成分权重；
- 股票日线行情；
- 复权因子；
- 成交量和成交额；
- 本地股票行业字段；
- 已经构建好的中证500研究面板。

Tushare Pro 已确认可用：

- `index_basic(market="CI")` 可以返回中信行业指数列表；
- `CI005001.CI` 到 `CI005030.CI` 对应中信一级行业指数；
- `index_daily(ts_code="CI005xxx.CI")` 可以返回中信行业指数日行情。
- 中信一级行业指数、中证全指、沪深300指数、股票日线、每日指标、复权因子、中证500权重和沪深300权重均已用 2010 年初小窗口验证可拉取。

### 2.2 不能直接使用的数据

当前账号调用 `index_member` 和 `index_weight` 时，普通指数和中信行业指数均返回空表。因此暂时不能直接从 Tushare 获得历史股票到中信一级行业的动态成分映射。

Tushare `stock_basic.industry` 可以返回行业字段，但其分类不是中信一级行业，不能直接当作原文口径。

## 3. 数据口径决策

采用以下折中口径：

1. 行业指数收益使用 Tushare 中信 `.CI` 行业指数原始日行情；
2. 股票到中信一级行业的归属使用显式维护的本地映射表；
3. 映射表由 Tushare 当前行业字段映射到中信一级行业，所有映射标记为 `industry_mapping_proxy`；
4. 无法可靠映射的股票不静默填充，记录为 `unknown`，并在覆盖率表中披露；
5. 报告中分开说明“中信行业指数原口径”和“股票行业归属 proxy”，不把结果描述为 Wind 精确复现。

映射表建议放在：

`data/reference/citic_level1_industry_mapping.csv`

字段至少包括：

| 字段 | 含义 |
| --- | --- |
| `source_industry` | Tushare `stock_basic.industry` |
| `citic_level1` | 中信一级行业名称 |
| `mapping_status` | `mapped`、`unknown` 或 `manual_review` |
| `mapping_note` | 映射解释 |

## 4. 因子定义

### 4.1 基础变量

对股票 `i` 和交易日 `t`：

```text
stock_ret(i,t) = close_adj(i,t) / close_adj(i,t-1) - 1
```

行业收益使用中信一级行业指数的日涨跌幅：

```text
industry_ret(g,t) = pct_chg(CI_level1_index(g), t)
```

量价排序变量按照报告定义：

```text
volume_price(i,t) = stock_ret(i,t) * volume(i,t)
```

为了避免不同量纲影响，仅用该变量对过去 20 个交易日排序，不直接把它作为最终因子值。

### 4.2 IMAX20

在每个股票的过去 20 个交易日中，找到个股涨幅最大的交易日 `t*`：

```text
IMAX20(i,t) = industry_ret(industry(i), t*)
```

### 4.3 ICM

在过去 20 个交易日中，按个股单日收益从大到小排序，取前 `n` 天。默认 `n=5`。

第 `j` 名的权重为：

```text
w(j) = 2^(-(j-1)/n)
```

因子为：

```text
ICM(i,t) = sum_j w(j) * industry_ret(industry(i), t_j)
```

其中 `t_j` 是个股过去 20 日中涨幅第 `j` 大的交易日。

### 4.4 VICM

将排序变量改为 `volume_price`，取过去 20 日中该变量最大的前 `n=5` 天：

```text
VICM(i,t) = sum_j w(j) * industry_ret(industry(i), t_j)
```

其中 `t_j` 按 `volume_price` 排名确定。

### 4.5 ICR 和 VICR

`ICR` 取过去 20 日中个股收益最小的前 `n=15` 天，对对应行业收益做半衰期加权：

```text
ICR(i,t) = sum_j w(j) * industry_ret(industry(i), t_j)
```

`VICR` 将排序变量替换为 `volume_price`，仍取最小的前 `n=15` 天。

### 4.6 CMC

行业联合动量复合因子定义为：

```text
CMC = VICM - VICR
```

由于 `VICR` 的方向通常为负向，减去 `VICR` 后将跌势中的反转信息统一转换为正向动量信息。

### 4.7 市场联合动量

将行业指数收益替换为中证全指 `000985.CSI` 的日涨跌幅，复用 VICM、VICR 和 CMC 的计算逻辑，形成市场联合动量复合因子。

## 5. 时间对齐和回测规则

为避免未来函数，统一采用以下规则：

1. 因子在交易日 `t` 只使用 `t` 收盘后已经知道的数据；
2. 股票收益和行业收益都使用复权或指数日涨跌幅，不使用未来数据；
3. 月频调仓时，使用当月最后一个可用交易日的因子值；
4. 因子分组收益从下一交易日或下一月开始计算；
5. 每只股票至少需要 20 个有效历史交易日；
6. 剔除上市未满 6 个月、ST、ST 摘帽 3 个月内以及过去 20 日停牌超过 5 日的股票；若本地字段不足以完整识别 ST 摘帽 3 个月，则先按可用字段执行，并在报告中披露无法完全对齐的过滤项；
7. 对中证500股票池，使用历史成分权重或历史成分状态，避免使用当前成分回看历史；
8. 复现报告中明确样本起止日期。当前本地缓存从 2018 年开始，但 Tushare 已验证可以补齐 2010 年以来股票和指数数据，因此主复现样本期设为 2010-01-01 至 2023-12-31，并可追加 2024-2026 作为样本外延长观察。

## 6. 验证项目

### 6.1 单元级验证

- 用 PDF 中的联合动量示例手算一个 `ICM` 值，和程序输出逐项对比；
- 检查权重是否满足第 1 名为 1、第 `n` 名为 0.5；
- 检查收益窗口不包含未来交易日；
- 检查缺失行业映射不会被静默填充；
- 检查负收益排序和正收益排序方向正确。

### 6.2 因子级验证

对 `IMAX20`、`ICM`、`VICM`、`ICR`、`VICR`、`CMC` 输出：

- 月度 RankIC 均值；
- RankIC 标准差；
- 年化 ICIR；
- RankIC 正值比例；
- 十分组月度收益；
- 多头、空头和多空收益；
- 累计净值和回撤。

### 6.3 稳健性验证

- `VICM` 的 `n=2,3,4,5,6` 敏感性；
- `VICR` 的 `n=10,15,20` 敏感性；
- 沪深300、中证500、中证1000和国证2000股票池；
- 行业内截面 RankIC；
- 剥离常见反转、换手、波动率和 Barra 风格暴露后的残差因子；
- 行业映射 proxy 覆盖率变化下的结果敏感性。

## 8. 风险和边界

1. 股票行业归属不是 Tushare 直接提供的中信历史成分，属于 proxy；
2. 2010 年以来数据需要重新从 Tushare 补齐，下载时间和缓存体积会显著增加；
3. Tushare 和 Wind 对复权、停牌、成交量和股票池过滤的细节可能不同；
4. `volume_price = return * volume` 对成交量口径敏感，需要保留替代版本 `return * amount` 做敏感性检查；
5. 复现成功的标准是方法、方向、稳健性和主要数量级接近，不要求所有数值逐位一致；
6. 本任务先复现论文因子，不直接将新因子加入现有 XGBoost 指增模型。接入指增属于后续独立实验，必须先通过本地因子验证。
7. ST 摘帽 3 个月过滤依赖历史名称或股票状态字段；如果 Tushare 当前接口不能稳定补齐，则该项只能作为缺口披露。
