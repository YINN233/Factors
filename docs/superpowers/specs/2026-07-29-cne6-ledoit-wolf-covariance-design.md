# CNE6 风险模型 Ledoit-Wolf 协方差改造设计

日期：2026-07-29

## 1. 背景

导师指出当前 CNE6-style 风险模型里“行业因子只保留对角方差”的处理太粗。这个意见是对的：如果行业之间相关性被强行设成 0，行业主动暴露的风险会被拆得比较机械，不能反映行业共振、产业链联动和风格-行业混合暴露。

当前实现里，所有因子都输出方差，只有 `country` 和 `style_*` 输出完整协方差，`industry_*` 只输出对角项。这样可以控制文件大小，但严格来说不是完整风险模型。

## 2. 改造目标

本次把正式风险归因使用的 252 日因子协方差改成 Ledoit-Wolf 收缩协方差矩阵，并覆盖 `country + style + industry` 全部共同因子。

核心变化：

1. 协方差估计从简单样本协方差改为 Ledoit-Wolf 收缩协方差。
2. 252 日窗口输出全因子完整协方差矩阵。
3. 60 日和 120 日窗口保留 compact 输出，避免文件体积过大。
4. 组合归因中的行业风险从“行业主动暴露平方乘行业方差”改成“行业主动暴露向量乘行业协方差矩阵再乘自身”。
5. 报告中不再说行业协方差没有展开，而是说明本版已经使用 252 日 LW 全因子协方差。

## 3. 为什么用 Ledoit-Wolf

风险模型里的因子数量比较多，尤其 Tushare 细行业超过 90 个。用 252 日窗口估计 100 多个因子的协方差时，样本长度和维度已经比较接近，普通样本协方差容易受噪声影响。

Ledoit-Wolf 的直觉是：不完全相信样本协方差，也不完全忽略因子相关性，而是把样本协方差向一个更稳定的目标矩阵收缩。这样通常能得到更稳定、条件数更好的协方差矩阵。

## 4. 输出口径

正式输出仍写入：

| 文件 | 内容 |
|---|---|
| `outputs/cne6_reproduction/factor_covariance_rolling.parquet` | 因子滚动协方差长表 |
| `outputs/cne6_reproduction/risk_model_diagnostics.csv` | 协方差和特异风险诊断 |
| `outputs/cne6_reproduction/portfolio_risk_attribution.csv` | 组合风险归因 |
| `docs/cne6_barra_risk_model_reproduction_2026-07-22.md` | 更新后的正式报告 |

252 日窗口输出全矩阵；60/120 日窗口保持 compact 输出，用于轻量诊断。正式组合归因默认仍使用 252 日窗口。

## 5. 验证

1. CNE6 smoke tests 需要覆盖 LW 协方差输出。
2. 252 日协方差诊断里 `covariance_type` 应出现 `ledoit_wolf_full`。
3. 252 日窗口行数应该显著高于旧版，因为行业和行业、行业和风格之间的协方差会被展开。
4. 组合归因的 `industry_var_daily` 必须使用行业协方差子矩阵，而不是只用对角线。
5. 报告中的风险模型诊断和局限性表述需要同步更新。

## 6. 边界

这仍然不是商业 Barra CNE6 的精确复制。商业模型可能还会做行业口径重映射、Newey-West 调整、特异风险结构化调整、贝叶斯收缩、因子收益稳健化等处理。本次重点是把行业协方差从“对角近似”推进到“可复现的 LW 全因子协方差”。
