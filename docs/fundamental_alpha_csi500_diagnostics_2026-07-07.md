## 诊断口径

推荐最终分使用上一轮入库建议的 8 个因子：

| 因子 | 含义 |
|---|---|
| `dupont_value_quality` | 净利率 + 资产周转 - PB |
| `cash_buffer_value` | 现金/负债 - PB |
| `robust_margin_value_ps` | 稳健净利率 - PS |
| `growth_value_balance` | 收入利润成长 - PE |
| `eps_bps_value_quality` | EPS + BPS - PB |
| `quality_growth_hmean` | 收入、利润、现金流同步成长 |
| `industry_neutral_roe_value_pb` | 行业内 ROE - PB |
| `liquidity_solvency_value` | 现金偿债 + 流动比率 - PB |

最终分定义：

```text
final_score = mean(percentile_rank(factor_i) - 0.5)
```

越大代表综合基本面分越高。该口径用 rank 合成，避免不同因子量纲直接相加。

## 使用建议

1. 2026 YTD 建议把 `quality_growth_hmean`、`eps_bps_value_quality`、`industry_neutral_roe_value_pb` 作为核心正向腿。
2. `cash_buffer_value` 和 `liquidity_solvency_value` 长期有效，但今年以来表现弱；组合里建议降权，或仅在防御/信用风险环境中启用。
3. 4 月是今年的明显失效窗口，后续需要做风格状态识别，避免价值质量类因子在特定月份集中反向。
4. 行业层面最终分当前偏向银行、仓储物流、证券、医药商业、食品；明显低配软件服务、半导体、区域地产、影视音像、通信设备、元器件。
5. 对通信设备要单独看：最终分暴露低，但行业内 RankIC 高，适合行业内相对选股，不适合直接用全市场最终分做行业配置。
6. 最新高分个股里银行和证券占比较高，进入组合前必须做行业权重、单票权重和中证500指数偏离约束。
