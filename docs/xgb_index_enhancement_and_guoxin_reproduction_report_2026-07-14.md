# XGBoost 指数增强策略与国信联合动量因子复现汇报

日期：2026-07-14

本文汇报两条主线：

1. 中证500 XGBoost 指数增强策略：在 65 个融量公开因子和 3 个自挖基本面因子的基础上，使用 XGBoost 做截面收益排序预测，并通过行业、风格、个股权重和主动风险约束构建指数增强组合。
2. 国信证券《个股与行业的共振：联合动量因子》复现：复现报告中的 `IMAX20 / ICM / VICM / ICR / VICR / CMC / MCMC` 因子，解释每个因子的计算过程和经济含义，并披露本地复现口径与 PDF 原始口径的差异。

## 一、结论摘要

### 1.1 XGBoost 指数增强

- 本轮严格限定在两个融量公开因子文本中的 65 个条目内，没有新增第 66 个公开候选因子。
- 65 个公开因子全部完成本地计算和二次验证：通过 40 个，隔离 21 个，失败 4 个。
- 相关性去重后，进入模型的公开因子为 37 个；再叠加 3 个前期自挖基本面因子，XGBoost 总输入特征数为 40 个。
- 当前模型后端已经切换为原生 `xgboost`，不是 `sklearn` fallback。
- 不加行业/风格约束的 XGBoost 组合在测试期表现较弱，测试期超额收益为 `-0.37%`，IR 为 `-0.25`。
- 加行业/风格 tight 约束后，测试期超额收益为 `3.32%`，IR 为 `2.50`，主动最大回撤为 `-0.61%`。
- 消融实验显示：公开因子裸用不稳定，但进入行业/风格约束框架后能提供有效信号；旧基本面因子仍然很强，不能说 XGBoost 已经完全替代基本面框架。

### 1.2 国信联合动量复现

- Tushare 已确认可以拉取 2010 年以来的中信一级行业指数 `.CI` 日线、股票日线、每日指标、复权因子、中证500权重和沪深300权重。
- `CI005001.CI` 到 `CI005030.CI` 对应中信一级行业指数，行业收益可以使用中信原口径。
- 当前 Tushare 账号下无法直接通过 `index_member/index_weight` 得到中信行业历史成分，所以股票到中信一级行业的归属使用本地映射 proxy。
- 2010-2023 全市场复现结果方向与 PDF 基本一致：`IMAX20 / ICM / VICM / CMC / MCMC` 为正向，`ICR / VICR` 为负向。
- 本地 `VICM` RankIC 均值为 `4.77%`，PDF 为 `5.90%`；本地 `CMC` RankIC 均值为 `4.69%`，PDF 为 `6.02%`；市场联合动量 `MCMC` 本地 RankIC 为 `6.67%`，接近或略高于 PDF 的 `6.40%`。
- 差异主要来自：Wind 与 Tushare 数据源差异、中信行业历史成分无法直接取得、股票行业归属 proxy、ST 摘帽过滤无法完全复刻、复权与停牌细节不同。

## 二、XGBoost 指数增强策略

### 2.1 任务背景

导师之前指出，原始指数增强方案更像“多因子选股”：模型给股票打分，然后直接买高分股票，缺少行业和风格约束。真正的指数增强应当以中证500为基准，在组合层面控制行业、风格、个股和主动风险，使组合整体仍然像中证500，只在可控范围内偏向 alpha 更高的股票。

因此本轮工作把策略拆成四层：

| 层级 | 作用 | 本轮实现 |
| --- | --- | --- |
| 因子层 | 从公开因子和基本面因子中提取 alpha 信号 | 65 个公开因子二次验证，选入 37 个；叠加 3 个基本面因子 |
| 模型层 | 学习多因子非线性组合 | 原生 `XGBRegressor` 预测未来 5 日截面收益排名 |
| 风险层 | 控制行业、风格、个股和 active share | tight/mid/loose 三套约束场景 |
| 回测层 | 检验组合是否稳定跑赢中证500 | 月度调仓、5bps 成本、测试期和 2026YTD 拆分 |

### 2.2 数据与样本切分

模型训练和回测主要使用本地中证500历史成分股面板。

| 区间 | 定义 | 用途 |
| --- | --- | --- |
| 训练期 | 2018-01 至 2022-12 | 训练 XGBoost |
| 验证期 | 2023-01 至 2024-12 | 因子筛选、模型验证 |
| 测试期 | 2025-01-02 至 2026-07-03 | 样本外组合评估 |
| 2026YTD | 2026-01-05 至 2026-07-03 | 今年以来稳定性观察 |

预测标签为未来 5 日收益的日截面排名：

```text
label = fwd_5d_rank
```

也就是说，模型不是直接预测未来收益率的绝对值，而是预测一只股票在当天中证500股票池内部未来 5 日表现的相对排名。

### 2.3 公开因子的 direct 与 proxy

65 个公开因子分成两类：

| 类型 | 含义 | 本轮数量 | 入模数量 |
| --- | --- | ---: | ---: |
| direct | 本地字段可以较直接复现原公式 | 27 | 16 |
| proxy | 原公式字段缺失，需要用本地字段近似替代 | 38 | 21 |
| total | 全部公开因子 | 65 | 37 |

`proxy` 不等同于原始生产字段。例如：

- `AF_CLOSE/AF_HIGH/AF_LOW/AF_OPEN` 映射到本地复权价；
- `AF_VWAP` 用成交额除以成交量近似；
- 主力资金流用 Tushare 大单、超大单资金流近似；
- CNE5 风格字段用本地规模、波动等风格 proxy 近似；
- `REINSTATEMENT_CHG_60D` 用 60 日复权收益近似。

因此，公开因子不能直接相信原文 IC 或 Sharpe，必须在本地中证500股票池上重新验证。

### 2.4 因子验证门

每个公开因子都经过以下验证：

1. 覆盖率检查：因子是否在大部分股票和交易日上可计算；
2. 训练期方向确定：确定因子是正向还是反向；
3. 验证期 RankIC 检验；
4. 测试期 RankIC 检验；
5. 2026YTD 稳定性检查；
6. 相关性去重：避免多个高度相似的因子重复入模；
7. 状态标记：
   - `passed`：允许入模；
   - `quarantined`：方向或近期稳定性有问题，隔离观察；
   - `failed`：验证失败，不入模。

结果：

| 状态 | 数量 |
| --- | ---: |
| passed | 40 |
| quarantined | 21 |
| failed | 4 |
| 相关性去重后入模 | 37 |

### 2.5 XGBoost 模型设置

模型后端：

```text
backend = xgboost
model = XGBRegressor
```

核心参数：

```text
n_estimators = 300
max_depth = 3
learning_rate = 0.05
subsample = 0.85
colsample_bytree = 0.80
reg_lambda = 5.0
reg_alpha = 0.1
objective = reg:squarederror
tree_method = hist
n_jobs = 4
```

建模逻辑：

1. 对每个交易日、每只股票计算 40 个特征；
2. 对训练期缺失值使用训练期中位数填充；
3. 用 XGBoost 拟合未来 5 日截面排名；
4. 输出每天每只股票的 `pred_rank`；
5. `pred_rank` 越高，模型越看好该股票未来 5 日相对表现。

模型 RankIC：

| period | RankIC mean | RankIC IR | positive ratio | n_days |
| --- | ---: | ---: | ---: | ---: |
| train | 0.1245 | 0.9883 | 84.67% | 1194 |
| valid | 0.0664 | 0.4492 | 67.36% | 484 |
| test | 0.0593 | 0.3433 | 61.06% | 357 |
| ytd_2026 | 0.0384 | 0.2270 | 54.39% | 114 |

解释：

- 训练期 RankIC 明显高于测试期，说明模型有学习能力，但也存在样本内更强的问题。
- 测试期 RankIC 为正，说明模型排序有样本外预测力。
- 2026YTD RankIC 仍为正，但强度下降，说明需要持续滚动监控。

### 2.6 3 个基本面因子

| 因子 | 计算过程 | 经济含义 | 使用方式 |
| --- | --- | --- | --- |
| `eps_bps_value_quality` | `rank(eps) + rank(bps) - rank(pb)` | EPS 高、每股净资产高，同时 PB 不贵，表示盈利能力和账面价值相对价格有吸引力。 | 作为价值质量底座，防止模型完全变成短期价量反转。 |
| `quality_growth_hmean` | `harm_mean(rank(revenue_yoy), rank(net_profit_yoy)) + rank(cashflow_to_profit)` | 收入和利润同步增长，并且利润能被现金流确认。调和平均会惩罚收入或利润单腿增长。 | 成长质量腿，偏好真实增长而不是单项高增长。 |
| `industry_neutral_roe_value_pb` | `industry_neutralize(rank(roe_ttm) - rank(pb))` | 在同一行业内部选择高 ROE、低 PB 的股票，降低行业估值结构差异。 | 更适合指数增强，因为它天然削弱行业暴露。 |

这 3 个因子是旧基本面因子里最适合进入指增模型的核心正向腿。它们的 XGBoost gain 分别为：

| 因子 | xgboost_gain |
| --- | ---: |
| `quality_growth_hmean` | 3.9965 |
| `eps_bps_value_quality` | 2.9027 |
| `industry_neutral_roe_value_pb` | 2.5544 |

### 2.7 37 个入模公开因子

下表逐项说明本轮真正进入 XGBoost 的 37 个公开因子。表里的“计算过程”是本地实现的简化表达，不是逐字复刻原始公开因子公式。

| 因子 | direct/proxy | 计算过程 | 经济含义 |
| --- | --- | --- | --- |
| `rl2_48_price_volume_decay_synergy` | proxy | 对收盘价做截面排名，再取 10 日时序百分位；成交量 12 日变化率做 60 日线性衰减；二者相乘后取负。 | 高价位和放量趋势叠加后容易形成拥挤，取负后偏向交易拥挤缓解或量价过热回落。 |
| `rl2_57_vol_adjusted_reversal` | direct | 计算日收益的带符号平方，取 30 日均值后取负。 | 惩罚持续极端收益，捕捉高波动上涨或下跌后的均值回归。 |
| `rl2_44_momentum_reversal` | direct | 每日复权收盘价做截面排名，计算排名变化，再累加 40 日排名变化并取负。 | 排名快速上升的股票后续可能回落；排名回落后可能有修复。 |
| `rl_03_pvt_covariance_reversal` | proxy | 构造 `PVT = 1日收益 * 成交量`，计算收益与 PVT 的 20 日协方差，做对数和截面标准化后取负。 | 价格上涨和放量高度共振时可能过度拥挤，取负捕捉量价拥挤后的反转。 |
| `rl2_54_turnover_volatility_inverse` | direct | 计算换手率 15 日标准差并取负。 | 偏好换手更稳定的股票，规避换手剧烈波动带来的交易拥挤和情绪扰动。 |
| `rl2_64_residual_volatility` | proxy | 对截面价格与成交量做回归，取价格无法被成交量解释的残差，再计算 20 日残差波动。 | 衡量价格相对成交量的异常扰动，反映交易行为中未被普通量能解释的异动。 |
| `rl2_65_turnover_volatility_momentum` | direct | 换手率 14 日波动做截面排名并平方取负，再乘以 30 日价格时序排名。 | 偏好价格位置较强但换手波动不极端的股票，避免动量信号被换手拥挤污染。 |
| `rl2_51_multidim_reversal` | direct | 价格相对 20 日均线、20 日均量、20 日平均换手分别排名，三者相乘后取负。 | 价格、成交量、换手同时偏高时视为过热，取负捕捉多维拥挤反转。 |
| `rl2_62_reversal_turnover_boost` | direct | 计算 `close / close_5d_ago * turnover_rate` 后取负。 | 短期涨幅叠加高换手代表追涨拥挤，取负后偏向短期过热回落。 |
| `rl_16_decay_volume_trend` | direct | 20 日线性衰减日收益乘以成交量对数，取近 3 日最大值后做截面标准化并取负。 | 近期放量上涨过强可能带来交易拥挤，取负捕捉短期量价趋势衰减。 |
| `rl_22_volume_divergence_momentum` | direct | 15 日均价排名与 15 日均量排名的 10 日相关性，再乘以收益、换手、成交量排名并取负。 | 当价量相关、收益、换手和量能共同偏高时，代表拥挤动量，取负偏向反转。 |
| `rl_23_turnover_relative_reversal` | direct | `- mean(turnover_rate,20) / mean(turnover_rate,120)`。 | 当前换手显著高于长期换手时，说明关注度异常升温，未来可能回归。 |
| `rl2_61_price_volume_divergence_cov` | direct | 计算成交量一阶变化与收盘价一阶变化的 30 日协方差并取负。 | 价量同步变化过强时容易拥挤，价量背离或同步减弱可能对应更好的后续收益。 |
| `rl_19_poly_volume_price_reversal` | proxy | 用成交量解释价格的滚动线性关系，取价格残差，加上收益峰度，并乘以成交量平方根后取负。 | 价格相对成交量解释框架出现异常，且收益分布尖峰厚尾时，可能代表异常拥挤或反转机会。 |
| `rl2_32_reverse_volatility_covariance_proxy` | proxy | 12 日成交量变化率与价格排名波动的 20 日协方差取负。 | 成交量变化和价格波动同步升高时代表交易不稳定，取负捕捉拥挤反转。 |
| `rl2_52_main_flow_peak_inverse` | proxy | 取 10 日主力资金流峰值的截面排名并取负。 | 主力资金短期极端峰值可能代表短期拥挤，取负后避免追逐资金流尖峰。 |
| `rl2_50_price_volume_volatility_inverse` | direct | 10 日价格波动排名与 10 日成交量波动排名相乘后取负。 | 价量波动同时高时风险较高，取负偏好价量更平稳的股票。 |
| `rl_11_large_outflow_reversal` | proxy | 构造 BBI 与 EMA60 价差，计算行业内离散度，叠加 3 个月涨幅和 PE 估值后取负排名。 | 行业内价格趋势与估值共同过热时容易回落，取负偏好趋势估值压力较低或有修复空间的股票。 |
| `rl_09_filtered_momentum_proxy` | proxy | 5 日价格变化加成交量和盈利收益率的对数项，做截面排名并取负，同时要求 PE 为正。 | 在估值过滤后识别短期量价动量过热，取负捕捉短期反转。 |
| `rl2_31_gap_momentum` | direct | 10 日均开盘价减 10 日均收盘价，再乘以 10 日价格变化排名。 | 开收盘缺口和短期动量结合，反映日内交易方向与隔夜/日内资金行为。 |
| `rl2_53_main_flow_stability` | proxy | 10 日主力资金流标准差取负。 | 偏好资金流更稳定的股票，规避资金流剧烈波动带来的噪声。 |
| `rl2_41_flow_volatility_factor` | proxy | 主力资金流 10 日百分位乘以 60 日成交量波动。 | 衡量资金流位置与成交量波动的耦合，捕捉资金流异动与流动性状态。 |
| `rl2_30_short_term_vol_adjusted_return` | direct | 15 日收盘价减开盘价之和做排名，乘以 15 日价格波动排名后取负。 | 短期日内上涨叠加高波动可能透支收益，取负偏向反转。 |
| `rl_07_log_volume_price_trend` | direct | 5 日价格变化乘以 10 日成交量对数，再做 10 日累加并取负对数。 | 短期放量价格趋势过强时可能拥挤，取负捕捉回落。 |
| `rl_06_vol_compression_momentum` | direct | 20 日价格振幅压缩程度乘以 30 日价格偏度排名并取负。 | 波动压缩后若价格偏度过强，可能是短期过热或突破失败风险。 |
| `rl2_40_style_ir_spread` | proxy | 本地 beta/波动 proxy 的 20 日 IR 减去 size proxy 的 20 日 IR。 | 衡量风格状态差异，捕捉 beta 与规模风格之间的阶段性相对强弱。 |
| `rl_15_nonlinear_price_volume_proxy` | proxy | 5 日收益正弦项、截面 VWAP 偏度、资金流正向天数中位数、价格区间和量能比率组成非线性项后取负。 | 非线性识别量价和资金流共振过热，捕捉复杂交易拥挤。 |
| `rl2_27_reverse_price_volume_rank` | direct | `- cs_rank(close) * cs_rank(volume)`。 | 高价格排名叠加高成交量排名可能代表拥挤，取负偏好低拥挤组合。 |
| `rl_14_large_outflow_reversal_dup` | proxy | 换手率加大单/超大单流出金额 60 日方差后取负。 | 大单流出压力和高换手共同代表抛压拥挤，取负后偏向流出压力缓和或反转。 |
| `rl_04_valuation_price_resid_proxy` | proxy | 1 年价格偏离、行业中性 PB、VWAP/成交量残差、5 日收益极值和盈利收益率组合。 | 把估值、价格残差和短期动量结合，寻找估值不贵且价格行为未过热的股票。 |
| `rl_13_fundflow_cross_section_pct` | proxy | 15 日价格腿乘以资金流正向天数的高分位门控，结果取整后做负排名。 | 当价格变化和资金流集中度同时高时视为短期资金拥挤，取负捕捉回落。 |
| `rl_26_moneyflow_drawdown` | proxy | 计算 15 日净资金流的最大回撤。 | 资金流回撤反映资金撤离压力，数值可用于识别资金流稳定性和抛压。 |
| `rl_01_tail_risk_reversal` | proxy | 5 日价格峰度、成交量偏度极值和 20 日短窗口收益极值组合后取负标准化。 | 捕捉尾部风险、成交拥挤和短期极端收益后的反转。 |
| `rl2_35_flow_momentum` | proxy | 主力资金流排名绝对值减超大单资金流排名绝对值，再做 15 日线性衰减。 | 比较主力和超大单资金行为，识别资金结构变化。 |
| `rl2_45_flow_momentum_reinstatement` | proxy | 60 日复权收益绝对值乘以 15 日衰减主力资金流。 | 价格复权冲击与资金流动量结合，识别资金对趋势冲击的确认。 |
| `rl_02_projection_support_proxy` | proxy | 5 日收益排名对 15 日均量排名做截面回归取残差，再叠加 20 日趋势、下影线支撑和主力流入/市值。 | 找到收益相对量能的异常部分，并用下影线和资金流判断是否有支撑。 |
| `rl2_37_flow_volatility_synergy` | proxy | 10 日衰减主力资金流乘以 60 日成交量波动。 | 衡量资金流动量与成交活跃度波动的共振。 |

### 2.7.1 未入模公开因子说明

下面 28 个公开因子完成了计算和验证，但没有进入最终 XGBoost 特征集合。原因分为三类：

- `quarantined`：验证期或测试期方向不稳，尤其是 2026YTD 变弱，需要隔离观察；
- `failed`：覆盖率、验证期 RankIC 或近期表现未过验证门；

## 三、国信证券联合动量因子复现

### 3.1 PDF 的核心思想

PDF 的研究问题是：一只股票大涨之后，到底是“孤立上涨、容易反转”，还是“有行业/市场大势支撑、可能延续”。

报告将个股自身上涨称为“小势”，将行业、板块和市场环境称为“大势”。

核心判断：

```text
个股大涨 + 行业也涨 = 共振上涨，后续更可能继续强
个股大涨 + 行业不涨 = 孤立上涨，后续更容易回落
个股大跌 + 行业也跌 = 可能是行业拖累，后续可能修复
个股大跌 + 行业不跌 = 可能是个股自身风险，后续可能继续弱
```

### 3.2 数据可得性与复现口径

已验证 Tushare 可以拉取 2010 年后的关键数据：

| 数据 | 可用性 | 说明 |
| --- | --- | --- |
| 中信一级行业指数 `.CI` 日线 | 可用 | `CI005001.CI` 至 `CI005030.CI` |
| 中证全指 `000985.CSI` | 可用 | 用于市场联合动量 |
| 沪深300指数日线 | 可用 | 可做指数池对照 |
| 股票日线 `daily` | 可用 | 2010 年初测试返回 1632 只股票 |
| 每日指标 `daily_basic` | 可用 | 2010 年初可拉 |
| 复权因子 `adj_factor` | 可用 | 2010 年初可拉 |
| 中证500权重 | 可用 | 2010 年 1 月返回 500 只成分 |
| 沪深300权重 | 可用 | 2010 年 1 月返回 300 只成分 |

当前限制：

- PDF 使用 Wind 和中信行业历史成分；
- Tushare 当前账号下 `index_member/index_weight` 对中信行业指数返回空表；
- 因此行业指数收益是中信原口径，但股票到中信一级行业的归属使用本地映射 proxy。

复现主样本：

```text
2010-01-01 至 2023-12-31
股票池：all
行业收益：Tushare 中信一级 .CI 指数
行业归属：Tushare stock_basic.industry -> 中信一级行业 proxy 映射
```

### 3.3 复现因子逐项解释

#### 3.3.1 IMAX20

计算过程：

1. 对每只股票，回看过去 20 个交易日；
2. 找到其中股票单日收益最大的那一天；
3. 取该股票所属中信一级行业在这一天的行业指数收益；
4. 这个行业收益就是 `IMAX20`。

公式：

```text
t* = argmax(stock_ret[t-19:t])
IMAX20 = industry_ret[industry, t*]
```

经济含义：

- 如果股票最大涨幅日行业也大涨，说明个股上涨有行业趋势支撑；
- 如果股票最大涨幅日行业不涨甚至下跌，说明个股可能是孤立上涨；
- 因子越高，代表个股大涨与行业大势越共振，后续更可能延续。

#### 3.3.2 ICM

计算过程：

1. 对每只股票过去 20 个交易日的单日收益排序；
2. 取涨幅最大的前 `n=5` 天；
3. 对这 5 天对应的行业收益做半衰期加权；
4. 涨幅最大的那天权重最高，第 5 名权重约为 0.5。

权重：

```text
w(j) = 2^(-(j-1)/n)
```

公式：

```text
ICM = sum_j w(j) * industry_ret[industry, t_j]
```

经济含义：

- 单日最大涨幅可能偶然，因此用前 5 个大涨日综合判断；
- 如果股票多个大涨日都伴随行业上涨，说明上涨背后有持续行业驱动力；
- 比 `IMAX20` 更平滑，因子值也更分散。

#### 3.3.3 VICM

计算过程：

1. 对过去 20 日计算 `stock_ret * volume`；
2. 取该变量最大的前 `n=5` 天，代表量价齐升最明显的交易日；
3. 对这些交易日对应的行业收益做半衰期加权。

公式：

```text
volume_price = stock_ret * volume
VICM = sum_j w(j) * industry_ret[industry, t_j]
```

经济含义：

- 放量大涨比普通大涨更可能代表资金进入；
- 如果放量大涨同时发生在行业上涨日，说明资金不仅买个股，也买行业主线；
- 这是 PDF 中行业联合动量最核心的增强版因子。

#### 3.3.4 ICR

计算过程：

1. 对每只股票过去 20 日单日收益排序；
2. 取跌幅最大的前 `n=15` 天；
3. 对这些下跌日对应的行业收益做半衰期加权。

公式：

```text
ICR = sum_j w(j) * industry_ret[industry, t_j]
```

经济含义：

- 如果股票下跌时行业也下跌，可能是行业拖累，个股存在修复可能；
- 如果股票下跌时行业仍强，说明个股自身可能有问题；
- PDF 中该因子原始方向通常为负，因此后续合成时会取反使用。

#### 3.3.5 VICR

计算过程：

1. 对过去 20 日计算 `stock_ret * volume`；
2. 取该变量最小的前 `n=15` 天，代表量价齐跌最明显的交易日；
3. 对这些交易日对应的行业收益做半衰期加权。

公式：

```text
VICR = sum_j w(j) * industry_ret[industry, t_j]
```

经济含义：

- 放量下跌比普通下跌更能体现资金抛压；
- 如果放量下跌伴随行业弱，可能是行业拖累；
- 如果放量下跌但行业不弱，更可能是个股自身风险；
- 因子原始方向为负，后续在 `CMC` 中用减法转换为正向信号。

#### 3.3.6 CMC

计算过程：

```text
CMC = VICM - VICR
```

经济含义：

- `VICM` 捕捉“放量大涨时行业也上涨”的正向共振；
- `VICR` 捕捉“放量下跌时行业表现”的反向信息；
- 二者相减后，把上涨共振和下跌反转信息统一成正向 alpha；
- `CMC` 是 PDF 中最核心的行业联合动量复合因子。

#### 3.3.7 MCMC

计算过程：

1. 把行业收益替换为中证全指收益；
2. 按照 `VICM` 和 `VICR` 的方式构造市场联合动量和市场联合反转；
3. 二者相减得到 `MCMC`。

公式：

```text
MCMC = VMCM - VMCR
```

经济含义：

- 行业共振看的是个股是否踩在行业主线上；
- 市场共振看的是个股是否顺着整个市场环境上涨；
- 在牛市或市场情绪强的时候，个股上涨更容易延续；在弱市中孤立上涨更容易失败。

### 3.5 结果解释

1. 方向基本复现成功：
   - `IMAX20 / ICM / VICM / CMC / MCMC` 都是正 RankIC；
   - `ICR / VICR` 都是负 RankIC；
   - 说明“个股与行业/市场共振”的核心经济逻辑在本地数据上成立。

2. 强度弱于 PDF：
   - 本地 `VICM` RankIC 为 `4.77%`，低于 PDF `5.90%`；
   - 本地 `CMC` RankIC 为 `4.69%`，低于 PDF `6.02%`；
   - 本地 ICIR 普遍低于 PDF，说明月度稳定性不如原文。

3. 多头收益较接近：
   - 本地 `ICM` 多头月超额为 `0.65%`，PDF 为 `0.63%`；
   - 本地 `VICM` 多头月超额为 `0.63%`，PDF 为 `0.68%`；
   - 说明高分组的实际收益贡献较接近。

4. 空头收益偏弱：
   - PDF 中空头端更强，本地空头端没有完全复现；
   - 这可能与行业归属 proxy、股票池过滤、数据源差异有关。

5. 市场联合动量 `MCMC` 复现最好：
   - 本地 RankIC 为 `6.67%`，PDF 为 `6.40%`；
   - 由于 `MCMC` 不依赖股票到中信行业的映射，只依赖中证全指收益，因此口径更干净。

### 3.7 国信复现的结论

可以向导师汇报：

> 国信联合动量因子的核心逻辑已经在本地 Tushare 数据上复现。行业收益使用中信 `.CI` 原始行业指数，样本期为 2010-2023。由于 Tushare 当前无法直接提供中信行业历史成分，股票行业归属使用 proxy 映射，因此结果不能视为 Wind 原始口径逐点复现。方向上，行业联合动量类因子均为正，行业联合反转类因子均为负，与 PDF 一致；强度上，本地 RankIC 和 ICIR 普遍弱于 PDF，但多头月超额接近，说明经济逻辑成立，口径差异主要影响稳定性和空头端表现。

## 四、两个任务的关系

XGBoost 指数增强和国信联合动量不是两个割裂任务。

它们可以形成后续研究路径：

1. 先把国信 `VICM / VICR / CMC / MCMC` 作为外源 alpha 候选；
2. 用现有外源因子接入口进行二次验证；
3. 如果在中证500上通过验证，再加入 XGBoost 特征集合；
4. 最终仍必须通过行业/风格约束组合回测，而不是只看单因子 IC。

推荐接入顺序：

| 优先级 | 因子 | 原因 |
| --- | --- | --- |
| P0 | `CMC` | PDF 主因子，结合行业上涨共振和下跌反转 |
| P0 | `MCMC` | 本地复现最强，且不依赖行业归属 proxy |
| P1 | `VICM` | 行业量价共振动量，经济含义清晰 |
| P1 | `VICR` | 行业量价齐跌反转，可作为 CMC 的组成腿 |
| P2 | `IMAX20 / ICM` | 结构简单，适合作为解释性基准 |

## 六、后续建议

1. XGBoost 指增不要直接扩大风险预算。当前最合理主线是 `xgb_industry_style_tight`，因为它测试期 IR 最高且主动回撤最小。
2. 公开因子需要滚动复检。当前 65 个公开因子里有 25 个没有进入模型，说明公开因子存在明显失效和口径不匹配。
3. 国信联合动量可作为新的外源 alpha 候选，但应先走二次验证流程，不能直接加入组合。
4. 如果导师要求更严格复现国信 PDF，应优先补齐中信行业历史成分映射；否则行业归属 proxy 会持续影响 ICIR 和空头端结果。
5. `MCMC` 因为不依赖行业归属，当前本地结果最干净，适合先接入现有验证框架。
6. 下一步可以做“国信联合动量因子加入 XGBoost 指增”的增量实验，比较加入前后测试期 IR、回撤、行业暴露和特征重要性变化。
