# 中证500基本面因子指数增强完整评估报告

日期：2026-07-07

研究对象：基于已挖掘的中证500基本面 Alpha 因子，评估其是否具备构建中证500指数增强组合的能力，并进一步检查超额收益的胜率、稳定性、分布特征、行业暴露和个股暴露。

## 1. 摘要结论

当前结论是：这些基本面因子具备中证500指数增强能力，但不适合把全部有效因子简单等权合成后直接使用。经过单因子诊断和参数网格测试，较优方案是使用 2026 年以来表现最稳定的 3 个核心因子做低强度 benchmark-plus 权重倾斜。

核心因子：

| 因子 | 经济含义 |
|---|---|
| `eps_bps_value_quality` | EPS + BPS - PB，衡量每股盈利和每股净资产相对估值的质量 |
| `quality_growth_hmean` | 收入、利润、现金流同步成长，避免单一成长指标失真 |
| `industry_neutral_roe_value_pb` | 行业内 ROE - PB，降低行业估值结构差异影响 |

最佳方案：

```text
factor_set = ytd_core3
rebalance = monthly
strength = 0.25
weight = benchmark_weight * exp(strength * zscore(final_score))
cost = 5bp per turnover
max_stock_weight = 2%
```

其中 `strength=0.25` 表示因子分数对基准权重的低强度倾斜，组合仍然主要贴近中证500基准。

核心表现：

| 区间 | 组合收益 | 基准收益 | 累计超额 | 年化算术超额 | 跟踪误差 | IR | 主动回撤 | 日胜率 | 月胜率 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| Full: 2018-01-31 至 2026-07-02 | 64.27% | 47.52% | 11.35% | 1.27% | 1.15% | 1.10 | -2.73% | 52.82% | 61.17% |
| Test: 2023-01-03 至 2026-07-02 | 49.43% | 41.62% | 5.51% | 1.53% | 1.25% | 1.22 | -2.73% | 52.07% | 65.12% |
| 2026 YTD: 2026-01-05 至 2026-07-02 | 10.01% | 6.29% | 3.50% | 7.32% | 1.68% | 4.36 | -0.39% | 55.93% | 85.71% |

主要判断：

1. `ytd_core3` 比上一轮推荐的 `recommended8` 更适合做指增。
2. 低强度 `strength=0.25` 的 IR 最高，适合稳健指增；提高强度可提高累计超额，但跟踪误差和主动回撤同步上升。
3. 日胜率长期只有 52%-53%，不是高日胜率策略；超额主要来自收益分布右尾更厚和亏损日损失较小。
4. 2026 年以来表现明显增强，尤其 2026Q2 是主要贡献窗口。
5. 最大不稳定窗口集中在 2024Q3/Q4。

## 2. 数据与回测口径

本次回测特别修正了真实收益口径。`data/processed/*.parquet` 中的 `close_adj` 已经做过截面标准化，是模型特征，不是真实可交易价格，因此不能用于回测。

本报告使用真实复权价格：

```text
real_close_adj = data/raw/daily.close * data/raw/adj_factor.adj_factor
return(T -> T+1) = real_close_adj(T+1) / real_close_adj(T) - 1
```

交易假设：

| 项目 | 设定 |
|---|---|
| 股票池 | 中证500历史成分股 |
| 信号时点 | T 日收盘可见的 PIT 基本面因子 |
| 调仓时点 | T 日收盘形成目标权重 |
| 持有收益 | T 到 T+1 复权收盘收益 |
| 组合类型 | long-only、满仓、benchmark-plus |
| 基准 | 每日归一化后的 `csi500_index_weight` |
| 交易成本 | 换手成本 5bp |
| 个股权重上限 | 2% |
| 当前未纳入 | 风险模型、真实停牌/涨跌停约束、成交额容量约束、指数调仓公告时点差异 |

相关实现和输出：

| 内容 | 路径 |
|---|---|
| 指增回测脚本 | `factors/reports/index_enhancement.py` |
| 稳定性诊断脚本 | `factors/reports/enhancement_stability.py` |
| 指增回测输出 | `outputs/fundamental_alpha_csi500_index_enhancement/` |
| 胜率稳定性输出 | `outputs/fundamental_alpha_csi500_index_enhancement_stability/` |

## 11. 风险与下一步

当前结论支持继续推进，但仍不是最终实盘组合。

下一步建议：

1. 加入行业主动偏离硬约束，例如单行业偏离不超过 1% 或 2%。
2. 加入个股主动权重约束，避免单票相对基准偏离过高。
3. 加入成交额、停牌、涨跌停过滤。
4. 加入换手预算，控制月度调仓冲击。
5. 引入市值、波动、Beta、行业等风险暴露约束。
6. 做成分调整公告时点校验，避免真实指数成分变动的时点偏差。
7. 继续监控 2024Q3/Q4 类似环境下的失效风险。

## 12. 最终判断

`ytd_core3_monthly_s0.25` 已经表现出可用的中证500指数增强能力：

1. Test 区间累计超额 5.51%，IR 1.22。
2. 2026 YTD 累计超额 3.50%，IR 4.36。
3. 长期日胜率约 52%-53%，2026 YTD 提升到 55.93%。
4. 年度层面只有 2019 年小幅负超额，2023 基本持平，其余年份为正。
5. 行业偏离较小，符合中证500指增的基本形态。

因此，这些因子可以作为中证500指数增强策略的 alpha 输入。更稳妥的实现方式不是直接高强度押注，而是低强度、基准权重附近的 benchmark-plus 倾斜，并配合后续组合优化约束。
