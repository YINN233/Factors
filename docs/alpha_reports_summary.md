## 总体脉络

这四份报告可以看作同一套 Alpha 研究体系的连续推进。

1. 二十三号报告先搭建“基本面因子自动挖掘”的底座：数据点时一致、量纲约束、算子体系、GP 搜索、LLM 辅助进化、因子池沉淀。
2. 二十八号报告把研究粒度推进到分钟频，围绕 A 股日内微观结构构建 60 分钟预测模型，并把预测落到“尾盘买入、次日上午卖出”的隔夜策略。
3. 二十九号报告进一步解释“为什么 A 股隔夜收益长期为负、日内收益为正”，并把隔夜/日内拆解用于单因子挖掘和跨股票领先滞后网络。
4. 三十号报告把二十三号的基本面框架与量价研究统一起来，强调因子挖掘不是简单公式生成，而是一条从数据、表达、搜索、评估到入库的研究生产线。

整体思想是：Alpha 研究要从“单个表达式回测”升级为“受约束、可解释、可复用、可持续迭代的因子工程体系”。LLM 和机器学习模型不是替代研究员下结论，而是作为候选生成、模式归纳和搜索加速工具，最后仍需经过点时一致、统计检验、相关性去冗余和样本外/交易成本验证。

## 一、专题（二十三）：融合 LLMs 进化的基本面因子挖掘统一框架

### 1. 报告定位

该报告讨论如何在基本面因子挖掘统一框架中引入大型语言模型。重点不是让 LLM 直接凭空生成因子，而是在已有的约束框架和 GP 进化体系中，把因子表现、因子含义和历史搜索结果提供给 LLM，让其辅助生成更可解释、更贴近人类研究逻辑的候选变体。

报告将因子挖掘范式分为三类：

| 范式 | 特征 | 优点 | 局限 |
|---|---|---|---|
| 手动挖掘 | 依赖研究员经验构建因子 | 解释性强 | 效率低、成本高、覆盖有限 |
| 算法挖掘 | 使用 GP、RL 等算法批量搜索 | 速度快、覆盖广 | 可解释性弱，容易产生噪声表达式 |
| Human-AI 交互 | LLM 理解因子含义，按人类要求辅助进化 | 能批量生成可解释候选 | 仍需强约束与严格验证 |

### 2. 统一框架

报告中的基本面因子挖掘流程可以概括为：

`因子生成 -> 因子计算 -> 因子验证 -> 因子筛选 -> Factor Pool`

在这一框架中，数据源包括季频财务数据、日频市值/一致预期等数据。核心是先保证点时一致和量纲合法，再用算子体系生成候选因子，最后通过线性 IC、非线性特征重要性、回测表现等指标筛选。

因子生成有三种方式：

| 生成方式 | 说明 |
|---|---|
| 随机法 | 用随机结构初始化启发式算法种群，同时限制结构复杂度和量纲合法性 |
| 枚举法 | 类似 OpenFE，在给定结构约束内做全局或局部搜索 |
| 领域知识法 | 由专家构造基本面因子，再用启发式算法、剪枝和基因结构分析优化 |

### 3. 因子计算与点时一致

报告提出两层因子计算结构。

第一层处理原始财务数据之间的计算，包括资产负债表、现金流量表、利润表和财务指标。利润表、现金流量表这类区间数据会被统一转为单季度数据，并基于公告期计算 TTM、YOY、QOQ 等口径。

第二层处理不同频率数据的结合。低频财务数据不能直接与日频市场数据拼接，而应按信息发布日期做 PIT（Point-in-Time）转换，把低频信息投射到每个交易日可见的数据序列，再与市值、一致预期等高频数据计算。

### 4. 量纲与算子体系

量纲控制是框架的关键。报告把数据大致区分为货币量纲、无量纲指标、市值类数据等，并设定运算规则：

| 算子类型 | 示例 | 量纲规则 |
|---|---|---|
| 元素算子 | `add(m1,m2)`、`sub(m1,m2)` | 通常要求输入量纲相同，输出保持量纲 |
| 比值算子 | `div(m1,m2)` | 同量纲相除输出无量纲 |
| 乘法算子 | `mul(m1,m2)` | 不同量纲相乘输出带组合量纲 |
| 时序算子 | `ts_mean`、`ts_std`、`ts_delta`、`yoy`、`qoq`、`ttm` 等 | 视算子含义保留量纲或输出无量纲 |
| 回归算子 | `ts_regression_slope`、`ts_regression_resi`、`ts_regression_rsquare` | 根据回归对象输出斜率、残差或拟合优度 |
| 截面算子 | `cs_norm`、`cs_minmax`、`cs_rank` | 输出无量纲得分 |

季频因子的窗口单位为季度，常数项覆盖 1 到 12 个季度；日频因子的窗口单位为月，覆盖约 1 到 12 个月。

### 5. 计算效率优化

报告指出传统 `groupby + rolling apply` 的复杂度约为 `O(M*T*N)`，其中 `M` 是股票数量，`T` 是时间长度，`N` 与滚动窗口长度相关。例如 5000 只股票、5 年、20 日窗口的 PE 均值，需要约 `5000*1250*20` 次计算。

框架采用 Cython 与流式计算把复杂度降到 `O(M*T)`。以 `ts_regression_slope` 为例，传统 `scipy.stats.linregress` 对单只股票两个因子做 1000 次、窗口为 12 的滚动回归耗时约 8.15 秒；Cython 加流式计算后约 0.07 秒，效率提升约 116 倍，其中 Cython 约 9.6 倍、流式计算约 12 倍。

此外，报告还构建了面向长表的 Pandas 算子和面向宽表的 NumPy 算子，并结合 lazy evaluation 与 cache，减少重复 resample 和重复计算。

### 6. GP 与 LLM 进化

GP 将因子表达式看作树结构，通过交叉、变异和子树替换生成新候选。报告强调 GP 本质上是前向随机变异，真正的进化来自筛选。为避免种群同质化，框架用锦标赛法和改进适应度筛选相关性低的个体。

LLM 的作用是分析已有因子的经济含义和表现，给出新候选。提示词要求 LLM：

| 要求 | 说明 |
|---|---|
| 目标 | 改善 IC 表现 |
| 约束 | 保持结构相对简洁，避免无意义复杂化 |
| 可变内容 | 替换算子、替换基础数据、调整窗口 |
| 输出 | 给出若干优化因子及改进原因，便于后续自动解析 |

用户提示会输入筛选出的高表现、高相关因子及其 IC，同时输入上一次 LLM 输出结果，要求本轮不要重复已有因子。报告中的示例显示，LLM 会输出一组表达式，并给出诸如提高敏感性、增强稳定性、增加区分度等解释。

### 7. 实证结果

报告使用 LightGBM 做模型回测。设置如下：

| 项目 | 设置 |
|---|---|
| 数据集 | 2017 年开始的全 A 数据 |
| 训练方式 | 3 年训练集、1 年验证集、3 个月滚动训练 |
| 回测区间 | 2021.1 - 2024.10 |
| 调仓频率 | 月初调仓 |
| 持仓数量 | 100 只 |

三组因子回测对比如下：

| 因子集 | Alpha | 累计收益 | 年化收益 | 夏普 | 信息比率 | 最大回撤 |
|---|---:|---:|---:|---:|---:|---:|
| Factor Zoo 12 个因子 | 68.37% | 53.65% | 12.40% | 0.47 | 1.34 | -31.53% |
| OpenFE 60 个因子 | 88.83% | 74.11% | 16.29% | 0.55 | 1.09 | -42.29% |
| Factor Zoo + OpenFE | 93.50% | 78.77% | 17.13% | 0.65 | 1.51 | -32.05% |

结论是：偏基本面的 Factor Zoo 因子收益更稳定，OpenFE 收益更高但回撤更大，两者融合后收益和稳定性均改善。

### 8. 小结

二十三号报告的核心贡献是把基本面因子挖掘标准化为一套工程框架，并将 LLM 放在“因子进化和研究反馈”的位置。LLM 提供候选方向，GP 和算子系统提供结构生成能力，统计评估与因子库筛选决定最终保留结果。

## 二、专题（二十八）：分钟因子模型

### 1. 报告定位

该报告在分钟频率上构建预测因子，并结合 A 股日内形态与微观结构特征，训练端到端的分钟频预测模型。最终目标不是高频日内频繁交易，而是利用分钟信号服务于隔夜交易策略。

策略核心是：在 14:40 生成预测信号，尾盘买入，次日上午卖出。

### 2. A 股日内股价形态

报告选取 2016-2022 年沪深 300 成分股，使用分钟价格并按开盘价归一化，得到典型日内形态：

| 时间段 | 观察结果 |
|---|---|
| 上午 | 股价整体稳步上升，开盘后半小时拉升最明显 |
| 10:15 左右 | 平均价格高点约 1.000691 |
| 下午 | 走势转为震荡下行 |
| 14:46 左右 | 平均价格低点约 1.000281 |
| 尾盘 15 分钟 | 常出现拉升 |
| 午间前后 | 价格波动较明显 |

基于该形态，报告比较两类交易方式：

| 策略 | 持仓交易时间 | 理论形态收益 |
|---|---:|---:|
| 日内策略：上午高点卖、下午低点买 | 约 180 分钟 | 约 4.1bp |
| 隔夜策略：尾盘买、次日上午卖 | 约 60 分钟 | 不考虑隔夜涨跌时约 11.9bp |

单纯隔夜持有并不能直接套利，因为 A 股长期存在负隔夜收益。以沪深 300 指数 2016-2022 年为例：

| 收益拆解 | 结果 |
|---|---:|
| 指数总收益 | 3.76% |
| 仅日内累计收益 | 215.47% |
| 日内平均每日收益 | 7.34bp |
| 仅隔夜累计收益 | -67.10% |
| 隔夜平均每日收益 | -6.34bp |

因此报告认为，需要在择时基础上叠加选股因子，用个股选择来克服平均负隔夜收益和交易成本。

### 3. 因子构建

报告使用 Alpha158 与 Factor Zoo 分钟频因子集。

Alpha158 来自 Qlib，借鉴经典量价因子构建方式，覆盖 K 线结构、滞后价格/成交量、动量、均线、波动率、回归斜率、残差、极值、分位数、排序、量价相关性、成交量变化等类别。报告延续此前研究结论，认为 Alpha158 作为机器学习输入优于 Alpha360。

Factor Zoo 因子来自报告团队此前构建的大量分钟数据因子，覆盖振幅、标准差、高阶矩、成交占比、流动性、动量、量价相关、极值位置等维度。原始 Factor Zoo 通常会在最后一步降频为日频，本报告移除降频步骤，将大部分因子恢复为分钟频序列。

最终保留的核心 Factor Zoo 分钟因子包括：

| 因子表达式 | 含义方向 |
|---|---|
| `Max($high,240)/Min($low,240)-1` | 日内振幅 |
| `Mad($high,240)/$close` | 高价绝对偏差相对收盘价 |
| `UpStd($close/Ref($close,4)-1,240)` | 4 分钟收益率上行波动 |
| `Kurt($close/Ref($close,4)-1,240)` | 高频收益分布峰度 |
| `Corr(Ref($high,1),$volume,237)` | 滞后高价与成交量相关性 |
| `Peak($close,240)` | 收盘价峰值位置或峰值结构 |
| `Min($close/Ref($close,7)-1,240)` | 7 分钟收益率阶段低点 |

### 4. 因子筛选

由于 Alpha158 与 Factor Zoo 全量分钟因子会造成内存和训练压力，报告先用 LightGBM 做特征重要性筛选。训练目标为未来 60 分钟收益率，最终取重要性排名前 20 的因子。

前 20 名因子中，Factor Zoo 因子占据前列，说明原本用于预测周线级收益的因子，去掉降频算子后仍能在分钟频模型中保持预测力。

筛选后的前 20 个输入包括：

1. `Min($close/Ref($close,7)-1,240)`
2. `Peak($close,240)`
3. `Corr(Ref($high,1),$volume,237)`
4. `Max($high,240)/Min($low,240)-1`
5. `UpStd($close/Ref($close,4)-1,240)`
6. `Kurt($close/Ref($close,4)-1,240)`
7. `CORR60`
8. `Mad($high,240)/$close`
9. `CORD60`
10. `WVMA60`
11. `RSV60`
12. `CORR30`
13. `CNTP60`
14. `MAX60`
15. `IMXD60`
16. `CNTN60`
17. `STD60`
18. `KLEN`
19. `CORR20`
20. `MIN60`

### 5. 模型框架

报告采用集成学习，融合 LightGBM 和 pegformer。

| 模型 | 负责信息 | 训练方式 |
|---|---|---|
| LightGBM | 截面非线性关系和因子交互 | 初始训练 2016-2020，验证 2021，每年滚动；使用 Qlib 默认超参 |
| pegformer | 个股时间序列局部形态和长程依赖 | 初始训练后每年用新增数据全量微调，学习率降为初始值的 1/10 |

pegformer 的核心结构为 `Patch Embedding + GRU + Transformer`：

| 模块 | 作用 |
|---|---|
| Patch Embedding | 把分钟长序列切成连续片段，降低序列长度并捕捉局部形态 |
| Transformer | 用自注意力捕捉全局长程依赖 |
| GRU | 保留片段间有序演化关系 |

模型输入为 `(b, t, f)`，其中 `t=240`，表示每个预测点使用过去 240 分钟信息；`f=20`，表示筛选后的 20 个因子。超参优化使用 Optuna，优化 patch 长度、patch 滚动间隔、Transformer 层数、特征长度、多头数等。

### 6. 因子与策略结果

LightGBM 与 pegformer 的预测结果等权相加，得到综合预测信号。虽然模型每分钟都可预测未来一小时收益，但实盘高频交易难度较高，报告最终使用 14:40 的信号作为当日交易依据。

样本外区间为 2022 年至 2025 年 7 月。综合预测因子的表现：

| 指标 | 数值 |
|---|---:|
| IC 均值 | 0.087 |
| IR | 9.136 |
| 分组表现 | 单调性较好，多空收益较均衡 |

策略设置如下：

| 项目 | 设置 |
|---|---|
| 回测区间 | 2022.1 - 2025.7 |
| 股票池 | 中证 1000 成分股 |
| 信号时点 | 当日 14:40 |
| 买入价格 | 当日 14:41 - 14:50 VWAP |
| 卖出价格 | 次日 10:11 - 10:20 VWAP |
| 持仓 | 等权买入得分最高的 50 只股票 |
| 手续费 | 双边千二 |
| 基准 | 中证 1000 |

策略整体表现：

| 指标 | 策略 | 基准 |
|---|---:|---:|
| 年化收益率 | 59.23% | -4.92% |
| 年化波动率 | 16.75% | 25.74% |
| 夏普比率 | 3.5355 | -0.1910 |
| 最大回撤 | -17.95% | -46.22% |
| 超额信息比率 | 2.2153 | - |

分年度表现：

| 年份 | 策略 | 基准 | 超额 |
|---|---:|---:|---:|
| 2022 | 67.35% | -21.56% | 88.91% |
| 2023 | -1.34% | -9.62% | 8.29% |
| 2024 | 118.53% | 4.97% | 113.55% |
| 2025 | 34.26% | 15.89% | 18.37% |

报告摘要中提到“64.15% 年化超额收益”，与表格中的策略年化 59.23% 和基准年化 -4.92% 相对应。

### 7. 交易成本压力

该策略日度调仓，年化换手约 250 倍，对交易成本高度敏感。报告做了成本压力测试：

| 成本假设 | 策略表现 |
|---|---|
| 双边千二 | 年化收益 59.23%，夏普 3.5355 |
| 双边千三 | 年化收益 23.84%，夏普 1.42 |
| 双边千四 | 仍能跑赢基准 |

### 8. 小结

二十八号报告的重点不是“分钟频就要高频交易”，而是用分钟频数据改进隔夜选股。报告先利用 A 股日内形态确定更有性价比的持仓窗口，再用 Alpha158 与 Factor Zoo 分钟因子训练集成模型，最终形成高收益但对交易成本敏感的隔夜策略。

## 三、专题（二十九）：隔夜-日内异象因子及领先滞后分析

### 1. 报告定位

该报告从收益分解出发，将传统日度收益拆为隔夜收益和日内收益：

| 收益 | 定义 | 含义 |
|---|---|---|
| 隔夜收益 C2O | 前一日收盘到当日开盘 | 非交易时段信息反应 |
| 日内收益 O2C | 当日开盘到当日收盘 | 连续竞价时段交易博弈 |

报告的核心问题是：全球市场通常存在正隔夜收益，但 A 股为什么长期表现为负隔夜收益、正日内收益？这一结构如何用于因子挖掘和跨股票领先滞后策略？

### 2. 全球市场与 A 股差异

2010 年以来主要指数的隔夜/日内收益对比显示，除上证指数外，多数海外市场隔夜收益为正。

| 指数 | 日内收益均值 | 隔夜收益均值 | 总收益均值 | 日内净值 | 隔夜净值 | 总净值 |
|---|---:|---:|---:|---:|---:|---:|
| 上证指数 | 0.100% | -0.087% | 0.013% | 36.965 | 0.033 | 1.224 |
| 德国 DAX | -0.001% | 0.043% | 0.042% | 0.784 | 5.158 | 4.041 |
| 恒生指数 | -0.044% | 0.058% | 0.014% | 0.149 | 8.268 | 1.231 |
| 纳斯达克 | 0.027% | 0.040% | 0.067% | 2.363 | 4.376 | 10.336 |
| 韩国综合 | -0.046% | 0.075% | 0.029% | 0.143 | 17.301 | 2.472 |
| 日经 225 | -0.004% | 0.052% | 0.050% | 0.716 | 6.744 | 4.825 |

全球正隔夜收益通常有三类解释：

| 解释 | 机制 |
|---|---|
| 风险溢价 | 闭市期间无法交易，投资者承担信息和流动性风险，需要补偿 |
| 微观结构 | 做市商日终平仓、散户开盘交易压力等推升开盘价 |
| 交易成本制衡 | 毛收益可能很高，但扣除交易成本后并不一定可套利 |

报告引用的美国市场研究显示，1993-2020 年“收盘买、开盘卖”毛收益可达 717%，但扣除佣金和买卖价差后净收益为 -32%，说明隔夜异象可能很大程度上被交易摩擦吸收。

### 3. A 股“隔夜负收益之谜”

A 股与全球多数市场相反，平均隔夜收益显著为负。报告将其主要归因于 T+1 交易制度。

T+1 使得开盘买入者不能在当日卖出，必须承受完整的日内波动且不能止损或获利了结。为了补偿这一“日内锁定”流动性风险，开盘价需要提供折扣，即开盘价相对公允价值偏低。由此形成：

| 现象 | 解释 |
|---|---|
| 负隔夜收益 | 开盘价被系统性压低 |
| 正日内收益 | 买方承担日内锁定风险后获得补偿 |
| 可转债对照 | 可转债不受 T+1 限制，因此不呈现同样的隔夜负收益结构 |

### 4. 非对称 U 形收益结构

报告进一步发现，A 股隔夜收益与前一日日内收益存在非对称 U 形关系。

按前一日日内收益排序后：

| 分组 | 现象 |
|---|---|
| 前 8 组 | 存在一定动量效应，前日日内收益越高，后续隔夜收益大体越高 |
| 第 9、10 组 | 结构反转，前日日内涨幅越高，后续隔夜收益越低 |

报告借助投资者关注的非对称性解释这一现象：投资者对负面信息和负回报更敏感，个股日内大跌后，隔夜期间可能产生更多负面讨论和关注。基于股吧帖子构造的非对称关注指数 AAI 与后续隔夜收益显著负相关，说明负面情绪在非交易时段发酵可能压低次日开盘。

### 5. 隔夜-日内因子构建

传统日频因子只使用日度收益，容易忽略隔夜与日内的结构差异。报告将价格和成交量拆分为隔夜/日内两段：

| 数据 | 定义 |
|---|---|
| 隔夜成交量 | 开盘集合竞价成交量，9:15 - 9:25 |
| 日内成交量 | 剔除开盘集合竞价后的连续竞价成交量，9:30 - 15:00 |

报告构建 9 大类、32 个隔夜-日内因子：

| 类别 | 代表因子 | 研究含义 |
|---|---|---|
| 动量/反转 | `overnight_momentum`、`intraday_reversal` | 隔夜或日内收益延续/反转 |
| 强度/背离 | `oi_spread`、`overnight_contribution` | 隔夜与日内收益差异及贡献 |
| 波动/稳定性 | `overnight_volatility`、`oi_correlation` | 隔夜波动和隔夜-日内联动 |
| 量价相关性 | `oi_volume_ratio`、`oi_volume_correlation` | 隔夜/日内成交量关系和量价关系 |
| 极值 | `max_drawdown`、`return_range` | 收益极差、回撤等极端特征 |

### 7. 领先-滞后网络与 d-LE-SC

报告引入“拔河效应”概念：隔夜收益与日内收益之间存在负相关，而且这种关系不仅发生在个股自身，也发生在跨股票之间。某些股票隔夜信息释放后，会驱动另一些股票日内价格修正。

为捕捉跨股票的领先-滞后关系，报告使用并改进 d-LE-SC（Directed Likelihood-Estimation Spectral Clustering）算法。

基本流程：

1. 将每只股票收益拆成隔夜收益和日内收益。
2. 计算股票 `i` 的过去 60 日隔夜收益与股票 `j` 的过去 60 日日内收益之间的相关性。
3. 构造非对称矩阵 `M`，行代表隔夜收益来源，列代表日内收益响应。
4. 对 `M` 取绝对值得到相关强度矩阵 `A`。
5. 使用有向图聚类把股票划分为领先组 `Clead` 和滞后组 `Clag`。

算法定义两个流量指标：

| 指标 | 含义 |
|---|---|
| 净流量 NF | 领先组流向滞后组的相关强度减去反向强度 |
| 总流量 TF | 两组之间双向连接强度总和 |

优化目标同时考虑方向性和连接强度，调节系数 `eta` 在 0 到 0.5 之间，越小越重视净流量方向。

### 8. 组合构建与回测

得到领先组和滞后组后，报告只使用领先组产生信号，交易滞后组股票，以隔离跨股票效应。

二十九号报告的贡献在于把 A 股隔夜/日内收益结构解释清楚，并将其转化为两类 Alpha 来源：一类是基于隔夜/日内拆分的单因子，另一类是跨股票有向网络中的领先-滞后关系。报告特别强调成交量相关性和成交量动量在该结构中的有效性。

## 四、专题（三十）：量价 X 基本面因子挖掘统一框架

### 1. 报告定位

该报告把量价因子与基本面因子统一到同一挖掘框架中。核心观点是：高质量因子不是把量价变量和财务变量简单相加，而是把“企业经营变化”和“市场定价确认”统一为可经横截面检验的定价模型。

报告把选股问题拆成两个问题：

| 问题 | 主要由谁回答 |
|---|---|
| 什么样的公司值得买？ | 基本面：盈利、现金流、资产质量、估值、成长等 |
| 什么时点适合买？ | 量价：趋势、成交、波动、流动性、市场确认等 |

### 2. 三大难点

| 难点 | 说明 | 框架处理 |
|---|---|---|
| 数据频率不一致 | 量价为日频或高频，财务为季频/月频 | 以公告时点为核心，把财务指标转换为逐日可用 PIT 信息 |
| 经济含义不同 | 量价反映交易行为，基本面反映企业经营质量 | 明确市场端做时点确认，基本面端做价值锚和质量约束 |
| 候选空间膨胀 | 自由组合会产生大量无效表达式 | 用量纲、语义、模板、分阶段评估控制搜索空间 |

### 3. 五层框架

报告将统一框架分成五层：

| 层级 | 作用 |
|---|---|
| 数据层 | 处理数据源组织方式和点时一致，量价数据展开为日频宽表，财务数据按公告日安全对齐 |
| 表达层 | 用字段分类、量纲边界和结构限制约束候选表达式 |
| 搜索层 | 生成量价因子、纯基本面因子、基本面与量价混合因子 |
| 评估层 | 同时考察 IC、换手、覆盖度、稳定性、相关性、复杂度等 |
| 资产化层 | 将通过筛选的因子沉淀到 Alpha 因子库，保留归档、IC 序列和验证结果 |

### 4. 算子体系

报告中的算子不是普通数学函数，而是已纳入表达式解析、量纲校验、候选生成和因子评估流程的可执行变换工具。

#### 4.1 基础算子

| 算子 | 含义 | 用途 |
|---|---|---|
| `safe_div(x,y)` | 带分母保护的比值 | 现金流覆盖、估值相对值、成交放大倍数 |
| `spread(x,y)` | 两变量差异的归一化表达 | 比较质量与风险、盈利与资本开支、短期与长期趋势 |
| `geom_mean(x,y)` | 几何平均 | 要求两个正向信号共同较强 |
| `harm_mean(x,y)` | 调和平均 | 对短板敏感，适合均衡质量结构 |
| `abs(x)` | 绝对值 | 幅度、偏离、风险强度 |
| `log(x)` | 对数 | 压缩市值、成交额、规模类偏态分布 |

#### 4.2 截面算子

| 算子 | 作用 |
|---|---|
| `rank(x)` | 转成横截面排序或分位，抗极端值 |
| `zscore(x)` | 转成横截面标准分，保留相对强弱幅度 |

常见混合结构是：基本面腿和量价腿先分别 `rank`，外层再用 `zscore` 统一总信号。

#### 4.3 单变量时序算子

主要用于量价因子和混合因子的市场确认：

| 算子 | 含义 |
|---|---|
| `ts_mean`、`ts_std`、`ts_sum` | 滚动均值、波动、累计 |
| `ts_delay`、`asof` | 滞后和低频数据可得值对齐 |
| `ts_delta`、`ts_pct` | 绝对变化和相对变化 |
| `ts_max`、`ts_min`、`ts_rank` | 阶段高低点和时序位置 |
| `ema` | 更重近期信息的趋势平滑 |
| `ts_slope`、`ts_resi`、`ts_rsquare` | 趋势速度、趋势偏离和趋势稳定性 |

#### 4.4 双变量时序算子

| 算子 | 用途 |
|---|---|
| `ts_corr(x,y,n)` | 判断两个变量滚动相关性 |
| `ts_beta`、`ts_regression_slope` | 判断敏感度或斜率关系 |
| `ts_regression_resi` | 刻画异常偏离 |
| `ts_regression_rsquare` | 判断关系稳定性 |

这些算子用于回答：价格变化是否伴随资金参与、成交放大是否转为价格确认、当前走势是否偏离正常量价关系。

#### 4.5 基本面衍生算子与中性化

| 算子 | 含义 |
|---|---|
| `yoy(x)` | 同比，衡量季节性调整后的改善/恶化 |
| `qoq(x)` | 环比，衡量最新一期边际变化 |
| `ttm(x)` | 最近四期滚动口径，降低单季波动 |
| `size_neutralize` | 控制市值规模暴露 |
| `industry_neutralize` | 控制行业暴露 |

中性化算子只能出现在表达式最外层，不能嵌套，也不能放在表达式中间。其定位是最终信号的风险暴露控制层，而不是普通变量变换。

### 5. 因子生成：量纲、语义、路径、模板

#### 5.1 量纲

报告强调，数学上能计算不代表经济上有意义。价格字段与利润字段直接相加、成交量与资产负债率直接相减，往往不可解释，即使样本内 IC 偶然较高，也更可能是噪声拟合。

框架将字段划分为：

| 量纲/类型 | 示例 | 可用方式 |
|---|---|---|
| 价格量纲 | 开盘价、最高价、最低价、收盘价、复权价 | 构造收益率、趋势、波动、回撤 |
| 交易活跃度 | 成交量、成交额、换手率 | 刻画参与度、拥挤度、资金关注 |
| 货币量纲 | 收入、利润、资产、负债、现金流 | 构造规模、覆盖率、资本结构 |
| 比率量纲 | ROE、ROA、毛利率、资产负债率 | 横截面排序、时序变化、同类比较 |
| 增长量纲 | 同比、环比增速 | 刻画改善/恶化 |
| 得分量纲 | `rank`、`zscore` 后的变量 | 可更灵活地组合 |

市值和收入都带货币单位，但经济含义不同，不能直接相加；它们适合构造成比值。

#### 5.2 语义

在量纲之外，报告进一步按经济语义组织字段：

| 语义类别 | 回答的问题 |
|---|---|
| 盈利能力 | 企业能否用资产和资本创造利润 |
| 成长性 | 企业经营状态是否改善 |
| 现金流质量 | 账面利润是否有真实现金支撑 |
| 资产质量 | 报表中是否隐藏减值或经营风险 |
| 偿债能力/流动性安全 | 企业是否有足够财务安全边际 |
| 资本结构 | 杠杆如何影响收益弹性和风险 |
| 营运效率 | 资产是否被有效利用 |
| 资本开支/再投资 | 企业是否为未来增长投入资源 |
| 股东回报 | 是否愿意且能够回馈股东 |
| 估值水平 | 市场价格是否充分反映基本面 |
| 量价确认 | 市场是否开始定价经营变化 |

这使因子生成从“字段组合”变成“经济命题组合”。

#### 5.3 三条生成路径

| 路径 | 说明 |
|---|---|
| 量价主导 | 用价格、成交量、成交额等市场变量，经时序与截面变换生成信号 |
| 基本面主导 | 用财务比率、增长关系、约束关系生成经济解释强的候选 |
| 混合路径 | 基本面变量作为核心指标，市场变量作为确认或惩罚指标 |

两个关键约束是：

| 约束 | 含义 |
|---|---|
| 量纲一致性 | 不让不同单位变量无意义混合 |
| 角色一致性 | 基本面描述经营状态，量价确认市场定价或交易约束 |

#### 5.4 混合因子模板

报告将成熟混合因子抽象为：

`f_i,t = g(F_i,t, M_i,t, P_i,t)`

| 部分 | 含义 |
|---|---|
| `F_i,t` | 基本面主线变量，刻画企业经营状态 |
| `M_i,t` | 市场确认变量，刻画市场是否开始定价 |
| `P_i,t` | 惩罚/过滤变量，抑制高风险、拥挤或失真结构 |
| `g` | 增强、确认、惩罚、筛选或非线性聚合方式 |

现金流质量修复的示例模板：

```text
zscore(((rank(amount/ts_mean(amount,20)) + rank(cashflow_to_profit)) - rank(capex_to_assets)))
```

其含义是：成交额放大代表市场确认，现金流利润匹配代表质量，资本开支压力作为惩罚。

### 6. 因子进化与筛选

报告把因子挖掘定义为多目标优化，而非最大化样本内 IC。

候选表达式空间先被压缩为受约束子集，约束包括：

| 约束 | 说明 |
|---|---|
| 输出量纲 | 因子输出必须符合目标量纲 |
| 量纲合法性 | 上下游运算必须量纲相容 |
| 语义合法性 | 字段角色与经济命题一致 |
| 时间可得性 | 避免未来函数，按公告时点和交易日可得性处理 |
| 复杂度 | 表达式深度和节点数不能失控 |

评价向量包括：

```text
(IC, -Turnover, -Complexity, -Redundancy, Robustness)
```

#### 6.1 强类型表达式树与 GP

量价和混合因子的主体搜索方法是强类型表达式树。叶子节点是行情、财务、行业、市值等字段；内部节点是横截面、时序、回归、条件过滤和四则运算等算子。

强类型的含义是：字段和算子都带量纲与语义，只有上下游相容时才允许扩展。GP 的初始化、变异、交叉都在这一边界内进行。

#### 6.2 热启动与 LLM 迭代

框架引入种子热启动，种子来自：

1. 已有有效因子；
2. 人工研究模板；
3. 历史表现较好的结构片段；
4. 外部研究假设。

LLM 的作用是把上一轮结果总结成结构化反馈，并生成下一轮候选假设。例如：

| 上一轮现象 | LLM 反馈方向 |
|---|---|
| 高 IC 因子集中在同一量价结构 | 保留经济主题，替换确认变量或财务腿 |
| 候选换手偏高 | 引入更平滑的窗口、低频确认或基本面锚定 |
| 表达式复杂但增量有限 | 推动结构简化 |
| 某股票池长期新增因子不足 | 提示切换主题方向 |

LLM 是研究助理和假设生成器，不是最终优化器。所有输出都必须经过字段白名单、量纲约束、语义约束、合法性检查、复杂度限制和样本评估。

#### 6.3 去冗余、两阶段评估和入库

报告区分两类冗余：

| 冗余类型 | 处理阶段 | 示例 |
|---|---|---|
| 结构冗余 | 统计评估前 | 重复排序、常数缩放、无意义嵌套、等价比值 |
| 预测冗余 | 完整评估后 | 因子值相关性高、IC 序列与 active 库高度同步 |

评估分两阶段：

| 阶段 | 目标 |
|---|---|
| 预筛 | 在代表性样本上快速计算 IC，低成本剔除明显无效候选 |
| 完整评估 | 在完整股票池和时间窗口中复核 IC、稳定性、覆盖率、换手、复杂度、相关性、分组收益、风险暴露 |

排序采用 Pareto 前沿和拥挤距离，避免用人为固定权重把 IC、换手、复杂度、冗余度和稳健性硬合成单分。入库时先看绝对 IC 门槛，再看与 active 因子库的 IC 序列相关性。若新因子明显更优，可替换旧因子；否则进入历史库，避免 active 库被同质化信号填满。

### 7. 实证结果

报告使用基础日频量价信息、三大财务报表和 Wind 金融指标表。数据起始日为 2016-01-01，预测目标为未来 5 日收益率，分别在中证 500 和沪深 300 中测试。

### 8. 小结

三十号报告是对二十三号报告的扩展和体系化。它把基本面因子的“价值锚”与量价因子的“定价确认”放入同一表达式树和评估框架中，强调研究资产的持续沉淀，而不是一次性回测。

## 五、四份报告的共同方法论

### 1. 点时一致是底线

四份报告都隐含或明确强调：任何低频或事件驱动数据都必须以真实可获得时间进入模型。基本面因子尤其需要按公告期 PIT 对齐；分钟因子和隔夜/日内策略则需要明确实际可交易时点和 VWAP 执行窗口。

### 2. 因子搜索必须受约束

无约束公式搜索容易产生样本内高 IC 但不可解释、不可复现的候选。报告反复使用量纲、语义、字段角色、复杂度和中性化位置约束，确保表达式至少具备可解释前提。

### 3. 单一 IC 不足以决定因子质量

真正可用的因子要同时满足：

| 维度 | 目的 |
|---|---|
| IC/IR | 预测能力 |
| 稳定性 | 跨时间、跨市场状态有效 |
| 覆盖率 | 能覆盖足够股票 |
| 换手 | 控制交易成本 |
| 复杂度 | 降低过拟合和解释成本 |
| 相关性 | 避免因子库同质化 |
| 分组收益 | 验证经济单调性和组合可用性 |

### 4. LLM 的正确位置是“辅助生成假设”

报告并未把 LLM 当作最终决策者。LLM 更适合：

1. 归纳已有高 IC 结构；
2. 解释因子经济含义；
3. 给出算子或字段替换方向；
4. 根据上一轮结果生成新种子；
5. 帮助研究员围绕主题持续迭代。

但因子是否有效，仍由点时一致、表达式合法性、样本检验、去冗余和回测验证决定。

### 5. 量价与基本面不是简单拼接

三十号报告给出了最清晰的表达：基本面负责回答“企业有没有价值变化”，量价负责回答“市场是否已经确认或正在定价”。真正好的混合因子通常是：

`基本面主线 + 量价确认 + 风险/拥挤惩罚`

而不是把财务指标和价格指标随意相加。

### 6. 微观结构可以转化为 Alpha

二十八和二十九号报告从 A 股 T+1、日内 U 形收益结构、负隔夜收益、开盘集合竞价成交量、隔夜/日内相关性等微观结构出发，构建了可交易信号。其共同启发是：市场制度和交易时段结构本身就是重要信息源。

## 六、对实现因子研究系统的启发

如果要把这四份报告转化为项目中的可执行系统，可以拆成以下模块：

| 模块 | 功能 |
|---|---|
| 数据对齐层 | 按公告日、交易日、分钟时间戳做 PIT 对齐，避免未来函数 |
| 字段元数据层 | 记录字段量纲、频率、语义类别、是否可用于 YOY/QOQ/TTM |
| 算子注册层 | 管理基础算子、时序算子、截面算子、基本面算子和中性化算子 |
| 表达式解析层 | 解析表达式树，检查量纲、语义、复杂度和中性化位置 |
| 候选生成层 | 支持随机、模板、枚举、GP、LLM 种子等生成方式 |
| 高效计算层 | 宽表 NumPy、长表 Pandas、Cython/Numba、cache/lazy、流式 rolling |
| 因子评估层 | IC、ICIR、分组收益、换手、覆盖率、相关性、风险暴露 |
| 去冗余层 | 表达式结构去重、因子值相关性、IC 序列相关性 |
| 因子库层 | active/history/archive 分层，记录版本、参数、样本和表现 |
| 策略验证层 | 根据信号时点、VWAP 执行窗口、手续费、换手、调仓频率做可交易回测 |

## 七、主要风险与注意事项

四份报告的风险提示基本一致，可以归纳为：

1. 所有结果都来自历史统计，未来可能因风格切换失效。
2. 模型训练存在随机性，初始化随机种子会影响单次结果。
3. 历史区间选择会影响结论，样本外和跨市场复核很重要。
4. 模型参数不同会改变最终表现。
5. 复杂模型对计算资源要求高，训练不足会导致欠拟合或不稳定。
6. 高频或高换手策略对交易成本、冲击成本、滑点和成交约束非常敏感。
7. 基本面数据必须严格按公告日和可得日对齐，否则容易产生未来函数。
8. 因子库扩张不能只看数量，应持续控制相关性和信息增量。

## 八、一句话总结

这四份报告共同构建了一条清晰的路线：用点时一致的数据和受约束的表达式树保证研究底座，用 GP、机器学习和 LLM 扩展候选空间，用多目标评估和因子库去冗余保证质量，再把 A 股特有的日内/隔夜微观结构与基本面价值变化统一进可交易、可复盘、可迭代的 Alpha 生产体系。
