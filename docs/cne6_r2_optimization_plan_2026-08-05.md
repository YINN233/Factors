# CNE6 中证500池内解释力优化计划

日期：2026-08-05

## 约束与目标

- 估计 universe 固定为历史中证500当日成分股，不引入全A股估计池。
- 优化对象是中证500池内的 CNE6-style 横截面收益分解，不把选股 alpha 的 IC 或组合超额替代风险模型 R²。
- 正式比较优先使用 `same_day + sqrt_mv`，同时保留 `equal`、调整 R² 和可交易的 `lagged_exposure_1d` 对照。
- 所有收益和暴露必须遵守可得时间；不能用成员筛选造成的跨日价格跳跃或未来行业标签提高 R²。

## 最终判断规则

1. 正式推荐不以自权重 R² 或单日最高 R² 为依据。
2. `same_day + sqrt_mv` 的平均/中位数/调整 R² 和共同样本结果必须同时改善，才认为解释力确实提升。
3. 若 R² 没有提高但残差波动、条件数或因子收益稳定性改善，记录为风险模型质量改善，不包装成 R² 达标。
