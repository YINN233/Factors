# 国信联合动量因子 Rolling 12M RankIC 趋势分组分析

日期：2026-07-15

这份文档是我在 `docs/xgb_index_enhancement_and_guoxin_reproduction_report_2026-07-14.md` 里“国信联合动量复现”部分基础上补的一版。导师主要问的是：既然 Rolling 12M RankIC 图是从 2010 年开始的，那前面的趋势到底怎么分段，每一段为什么会上升或下跌。所以我这份报告就按这个问题来展开。

## 1. 我先把口径说清楚

原图是这张：

![](../outputs/guoxin_co_momentum_reproduction/monthly_rankic.png)

这张图标题写的是 `Rolling 12M RankIC`，但我检查代码后发现，本地实际用的是 `rolling(12, min_periods=3)`。这点需要先说清楚，否则前几个月很容易被误读：

- 2010 年前几个月还不是严格的 12 个月均值，而是至少有 3 个月数据后就开始画出来；
- 到 2011 年以后，才基本可以把它当成完整 12 个月滚动 RankIC 来看；
- 图里的 `ICR / VICR` 是原始 RankIC，不能简单理解成“线往下就是变差”。

还有一个更容易踩坑的地方：国信这几个因子的方向并不完全一样。

| 分组 | 因子 | 方向解释 | 经济含义 |
| --- | --- | --- | --- |
| 上涨共振组 | IMAX20 / ICM / VICM | 原始 RankIC 越高越有效 | 判断个股上涨是否有行业上涨支撑；牛市或行业主线清晰时更强。 |
| 下跌共振/反转组 | ICR / VICR | 原始 RankIC 越负越有效；方向调整后越高越有效 | 判断个股下跌是行业拖累还是个股自身风险；弱市和风险释放期更有解释力。 |
| 复合组 | CMC / MCMC | 原始 RankIC 越高越有效 | 同时吸收上涨共振和下跌反转；MCMC 使用全市场收益，受行业映射 proxy 影响更小。 |

所以我后面同时看两个口径：

```text
原始 rolling_12m_rankic = rolling_mean(monthly_rankic, 12)
方向调整后 rolling_12m_rankic = rolling_mean(monthly_rankic * direction, 12)
```

其中 `ICR / VICR` 的 `direction = -1`。方向调整之后，所有因子都统一成“数值越高，因子越有效”，这样才方便横向比较。

## 4. 分阶段看，我的理解是

### 4.1 2010.03-2010.12：因子从不稳定转向有效

2010 年初，`IMAX20 / ICM / VICM / CMC` 的滚动 RankIC 一度为负或接近 0。到 2010 年底，`VICM` 从 `-2.27%` 升至 `4.11%`，`ICM` 从 `-2.11%` 升至 `3.49%`，`CMC` 从 `-1.93%` 升至 `3.23%`。与此同时，`ICR / VICR` 原始 RankIC 从小正值转为负值，方向调整后代表下跌反转腿也在增强。

宏观背景上，2009 年大规模信贷刺激后，2010 年进入政策退出和流动性边际收紧阶段，通胀和地产调控也压制整体估值扩张。市场不再是简单的单边 beta 行情，行业之间开始分化。在这种环境下，个股上涨如果同时有行业或市场支撑，就更容易被市场理解成“真实主线”，而不是单只股票的短期异动；个股下跌如果只是行业拖累，也更容易出现修复。所以我理解这里上涨共振和下跌共振两条腿都开始变得有效。

### 4.2 2011-2012：震荡弱市中复合共振和下跌反转继续增强

2011-2012 年，`CMC` 从 `3.23%` 升至 `5.57%`，`VICR` 原始 RankIC 从 `-2.77%` 下降至 `-4.96%`，方向调整后代表放量下跌反转腿增强。`MCMC` 维持在约 `6%-7%` 的较高水平。

这一阶段 A 股整体偏弱，宏观上又叠加了 2011 年通胀压力、货币政策偏紧、欧债危机扰动和国内经济增速放缓。2012 年政策逐步转向稳增长，但市场风险偏好恢复并不顺畅。弱市中，一个股票下跌以后，市场更关心它是“被行业或市场系统性拖累”，还是“公司自身风险”。如果下跌发生在行业也弱的日子，后续修复概率更高；如果行业不弱而个股自己跌，后续可能继续弱。这也是我认为 `ICR / VICR` 在这一段更有效、`CMC` 又比单纯上涨共振更稳的原因。

### 4.3 2013-2014：上涨共振弱化，下跌反转增强

2013-2014 年，图中最明显的现象是分化：`IMAX20` 从 `3.26%` 降至 `-0.25%`，`VICM` 从 `5.34%` 降至 `1.90%`，上涨共振组明显弱化；但 `ICR` 原始 RankIC 从 `-3.89%` 降至 `-7.56%`，`VICR` 从 `-4.96%` 降至 `-7.58%`，下跌反转组增强。

这一段比较特殊，不能只从指数涨跌去解释。2013 年“钱荒”使银行间流动性风险暴露，影子银行和非标融资压力上升；同时创业板、TMT、并购重组等成长主题很强，很多行情并不是中信一级行业指数能完整解释的。换句话说，很多个股上涨来自更细分的主题、风格和估值扩张，不一定来自一级行业整体上涨，所以 `IMAX20 / ICM / VICM` 这类一级行业共振腿会走弱。相反，流动性冲击和信用收缩环境下，行业性下跌更容易带来错杀修复，所以下跌共振/反转腿增强。

### 4.4 2015：杠杆牛和股灾使上涨共振大幅增强

2015 年是这组因子最容易解释的一段。`VICM` 从 `1.90%` 升至 `10.11%`，`ICM` 从 `2.15%` 升至 `8.14%`，`MCMC` 从 `6.49%` 升至 `11.37%`，`CMC` 从 `5.84%` 升至 `9.21%`。

我的理解是，2015 年 A 股最典型的特征就是同涨同跌和杠杆资金。降息降准、居民资金入市、融资交易扩张推动上半年杠杆牛；6 月以后快速去杠杆和股灾又造成剧烈波动。这样的市场里，个股大涨如果同时伴随行业或市场大涨，往往说明它不是孤立异动，而是主线行情的一部分；放量大涨的 `VICM` 尤其有效。`MCMC` 也很强，说明市场整体风险偏好和 beta 对个股后续收益的解释力在这一阶段很高。

### 4.5 2016：高点滞后出现，随后回落正常化

虽然股灾发生在 2015 年，但许多因子的 Rolling 12M 高点出现在 2016 年。比如 `CMC` 原始峰值在 2016 年 4 月，为 `13.44%`；`VICM` 峰值在 2016 年 5 月，为 `14.28%`；`MCMC` 峰值在 2016 年 7 月，为 `15.49%`。

这看起来像是滞后，其实并不矛盾，因为图本来就是 12 个月滚动均值。2016 年上半年仍然包含 2015 年杠杆牛、股灾、反弹等极端样本，所以滚动 RankIC 会滞后见顶。随后，2015 年极端行情逐渐退出窗口，市场微观结构恢复，政策也更强调稳定和去杠杆，联合动量因子的强度开始回落到更正常的水平。

### 4.6 2017-2018：行业共振重新强于市场共振

2017-2018 年，`IMAX20` 从 `2.66%` 升至 `6.23%`，`ICM` 从 `4.54%` 升至 `6.37%`，`VICM` 从 `5.29%` 升至 `6.81%`。但 `MCMC` 从 `9.40%` 降至 `7.47%`。

这个组合说明一件事：市场整体共振已经不如 2015-2016 那么强，但行业主线仍然有用。宏观上，2017 年金融去杠杆、资管新规预期、供给侧改革继续影响市场结构；2018 年中美贸易摩擦、信用收缩和权益市场下跌压制整体风险偏好。整体 beta 不强，但白马消费、金融、周期、后期逆周期政策相关行业之间仍有清晰分化。因此，行业维度的上涨共振比市场整体共振更有解释力。

### 4.7 2019-2021：联合动量因子最明显的系统性衰减阶段

2019-2021 年是我觉得最需要单独跟导师解释的一段，因为这里不是简单的短期波动，而是比较明显的系统性衰减。方向调整后，几乎所有组别都下行。`CMC` 从 `6.25%` 降至 `-2.17%`；`MCMC` 从 `7.47%` 降至 `2.10%`；`VICM` 从 `6.81%` 降至 `1.28%`；`ICR / VICR` 方向调整后也从正值跌到负值。

我理解主要有三个原因：

1. 2019 年以后市场进入结构性行情，科技、消费、医药、新能源等赛道行情持续演绎，风格因素和估值扩张的重要性上升；
2. 2020 年疫情冲击后，流动性宽松强化了成长风格和核心资产行情，个股收益更多由赛道、风格和拥挤交易决定；
3. 中信一级行业过粗，无法完整刻画新能源车、光伏、半导体、CXO 等细分赛道的共振。

所以这一阶段，“个股和一级行业/全市场是否共振”对未来收益的解释力明显下降。尤其是下跌反转腿失效，说明弱势股票并不一定因为行业拖累而修复，很多时候是风格出清、估值压缩或基本面预期恶化导致的持续弱势。

### 4.8 2022-2023：弱市中下跌反转和复合共振重新有效

2022-2023 年，`ICR` 原始 RankIC 从 `4.57%` 降至 `-5.53%`，`VICR` 从 `4.51%` 降至 `-5.52%`。因为它们是反向因子，所以这是非常明显的修复。`CMC` 从 `-2.17%` 修复到 `4.49%`，`MCMC` 从 `2.10%` 修复到 `5.28%`。相比之下，`IMAX20 / ICM / VICM` 的修复较弱。

这一阶段宏观压力比较集中：疫情反复和防控政策变化影响经济活动，地产信用收缩压制居民和企业预期，美联储快速加息又压低全球风险偏好，A 股很难形成持续单边行情。弱市里，纯上涨共振不容易持续，因为市场轮动快、追涨容易失败；但“下跌到底是系统性拖累还是个股自身风险”变得更重要。因此，下跌共振/反转组和复合组明显修复。

## 5. 后面使用这些因子时，我的判断

1. 不能只看原始 Rolling RankIC 图判断因子增强或失效。`ICR / VICR` 原始线下行才是有效性增强，必须做方向调整。
2. `VICM / ICM / IMAX20` 更像上涨行情和行业主线因子。它们在 2015、2017-2018 更强，但在 2019-2021 结构性赛道行情中明显弱化。
3. `ICR / VICR` 更像弱市修复和风险识别因子。它们在 2011-2012、2013-2014、2022-2023 更有解释力，但在 2019-2021 赛道强者恒强阶段失效。
4. `CMC` 是行业层面的复合因子，长期比单腿更平衡，但会受行业归属 proxy 和一级行业过粗影响。
5. `MCMC` 是市场层面的复合因子，不依赖股票到中信行业的映射，因此本地复现口径最干净，也更适合作为后续接入 XGBoost 指增的候选外源 alpha。

## 6. 我向导师汇报时可以这样说

> 从 2010 年开始看，国信联合动量因子并不是一直单调有效，而是明显依赖市场状态。2010-2012 是从不稳定到稳定有效的起步期；2013-2014 上涨共振弱化但下跌反转增强；2015-2016 在杠杆牛和股灾后达到高点；2017-2018 行业主线重新强于市场整体共振；2019-2021 是因子系统性衰减阶段，主要受结构性赛道行情、风格拥挤和一级行业口径过粗影响；2022-2023 弱市环境下，下跌反转和复合共振重新有效。因此，这类因子后续更适合做状态分层使用，而不是无条件固定权重使用。
