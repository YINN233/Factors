# CNE6 中证500池内解释力优化结果

日期：2026-08-05

## 结论先行

本轮没有扩大到全 A 股，正式估计 universe 始终是历史中证500当日成分股。通过修复收益时间连续性、改进非线性规模描述子并保持 `same_day + sqrt_mv` 评价，平均横截面 R² 从历史基线 0.3790 提升到严格重算的 0.3876，平均调整 R² 从 0.2088 提升到 0.2192。提升是真实的，但仍不足以支持“达到 0.5”的结论。

行业池化、去掉行业、Huber 稳健回归和删除任何一个风格块都没有超过严格 P0。因此当前正式结果保留原始细行业、九类风格和市值平方根 WLS；其他方案作为诊断输出保存。

## 样本与时间口径

|项目|结果|
|---|---:|
|正式估计池|历史中证500当日成分股|
|完整历史面板|5,372,948 行、1,651 只股票|
|正式回归面板|1,938,588 行、3,986 个交易日|
|主收益口径|`same_day`：当天暴露解释当天收益|
|主回归权重|`sqrt(total_mv)`|
|历史基线成功回归日|3,985|
|严格 P0 成功回归日|3,986|

收益先在成员过滤前的完整历史上计算。按全市场交易日序号检查相邻性后，完整历史中 16,422 个跨空档位置的 `returns_1d` 和 `fwd_1d_return` 均置为缺失，避免把停牌或记录空档当成一日收益。随后才筛选当日中证500成员进入回归。

## 主结果

历史基线来自 `docs/cne6_regression_r2_return_definition_comparison_2026-07-29.md` 的 `same_day` 结果；P0 使用当前 gap-aware 面板和完整历史滚动暴露严格重算。两者共同日期为 3,985 天。

|方案|平均 R²|中位数|平均调整 R²|R² > 0.5|平均残差标准差|
|---|---:|---:|---:|---:|---:|
|历史基线|0.3790|0.3706|0.2088|9.39%|0.01881|
|严格 P0：连续收益 + 非线性规模|0.3876|0.3774|0.2192|11.11%|0.01679|
|P0 相对基线变化|+0.0086|+0.0068|+0.0104|+1.72 个百分点|-0.00202|

分段共同样本中，P0 相对基线的平均 R² 增量在 2012+ 为 `+0.0086`，在 2018+ 为 `+0.0092`。2018+ 的 P0 平均 R² 为 0.4179、平均调整 R² 为 0.2661，仍低于 0.5。

## 行业与回归对照

所有结果均使用严格 gap-aware 面板和相同的 `same_day + sqrt_mv` 评价口径。

|方案|平均 R²|中位数|平均调整 R²|平均行业数|平均条件数|结论|
|---|---:|---:|---:|---:|---:|---|
|原始细行业 + WLS|0.3876|0.3774|0.2192|95.91|190.49|正式采用|
|稀疏行业 `min_obs=5`|0.2594|0.2440|0.1836|36.95|62.23|不采用|
|稀疏行业 `min_obs=10`|0.1805|0.1604|0.1424|13.72|14.69|不采用|
|无行业|0.1190|0.0996|0.1025|0|3.23|不采用|
|Huber IRLS|0.3557|0.3449|0.1784|95.91|190.49|稳健性诊断，不替换 WLS|

池化后 R² 大幅下降，说明当前细行业标签确实吸收了较多横截面共同波动；但它来自静态 `stock_basic` 行业字段，不应被解释成历史 PIT 商业 Barra 行业口径。没有历史生效行业映射前，正式报告保留该限制。

## 风格 leave-one-out

严格 P0 的平均 R² 为 0.3876。下表删除一类风格后重新回归，所有删除方案均下降。

|删除风格|平均 R²|相对 P0|
|---|---:|---:|
|规模|0.3806|-0.0070|
|波动率|0.3811|-0.0066|
|流动性|0.3814|-0.0063|
|动量|0.3760|-0.0116|
|价值|0.3842|-0.0034|
|成长|0.3854|-0.0023|
|质量|0.3850|-0.0026|
|股息率|0.3860|-0.0017|
|Sentiment|0.3837|-0.0039|

因此九类风格整体保留。Sentiment 仍只是 Tushare `report_rc` 结构化字段构成的公开代理，不宣称是商业 Barra Sentiment 的精确字段；删除它会降低解释力，但不能单独证明代理口径正确。

## 正式采用与不采用

正式采用：

- 完整历史收益和滚动暴露计算，再按当日中证500成分筛选。
- gap-aware `returns_1d`/`fwd_1d_return`。
- 线性市值控制后的非线性规模描述子。
- 原始细行业、九类风格、`same_day + sqrt_mv` WLS。

暂不采用：

- `industry_min_obs=5/10` 或无行业模型：解释力下降。
- Huber：原始收益评价 R² 低于 WLS；可用于异常收益稳定性诊断。
- 逆特异风险自权重：容易造成有效样本数低于因子数的伪高 R²。此前温和风险排名权重的交叉评价最高约 0.3951，也没有达到 0.5。
- 删除任一风格块：严格共同样本中均下降。

## 下一步

若要继续靠近导师的 0.5 参考线，优先级不是继续调权重，而是补历史生效的 PIT 行业分类、商业模型对应的描述子定义和更可靠的财务/分析师数据。只有在这些口径补齐后，才值得继续比较行业内标准化、描述子级组合和协方差约束；当前公开代理数据下，应把 0.3876 作为诚实的可复现结果。
